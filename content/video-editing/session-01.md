# Video Editing Foundations and Workflow

## A. Session Identification
<!-- kind:identification -->
**Week / module:** Week 1 — Module 1: Foundations and Story

**Recommended duration:** 105 minutes

**Difficulty:** Beginner (first contact with editing)

**Prerequisite knowledge:** Basic computer or phone confidence — opening an application, creating and saving a file, using a browser, copying files. No editing knowledge and no camera are assumed. If a learner struggles with mouse and keyboard, pair them with a confident learner for the first practical.

**Connection to previous work:** This is the first session of the course. There is no previous editing session. It connects to everyday life: nearly every learner has phone footage — a birthday, a church event, a shop product — that was shot and never finished. Today we explain why that footage is stuck, and we start freeing it.

**Preparation before class:** Academy computers on and logged in; a projector connected; Footage Pack A (Talking Head) copied to a shared class folder and verified (plays correctly, manifest matches contents, consent note present); printed shot-log sheets and folder-structure handouts (one per learner); the four aspect-ratio diagrams (16:9, 9:16, 1:1, 4:5) drawn or printed for the board; a spare 16 GB USB drive ready for any learner without one; the Course Design Document Section 15 ethics rules read aloud at the start. Instructor note on tone: This session must feel empowering and practical, not theoretical. Learners should leave feeling "I now know why my videos were stuck, and I know the first real step." Keep the mood confident, warm and hands-on. Say the academy philosophy early: "From Zero to Expert, Together."

## B. Learning Outcomes
<!-- kind:outcomes -->
By the end of this session, the learner will be able to:
1. Explain in their own words what an editor actually does — deciding what the audience sees, in what order, and for how
long — and why editing is a decision-making job, not a button-pushing job.
2. Describe the full post-production workflow in order, from ingest (receiving footage) to archive (storing the finished
project), using all ten stage names correctly.
3. Organise a footage pack into a clean folder structure with consistent file names, so every clip can be found in under ten
seconds.
4. Back up footage so that every clip exists in two separate places before editing begins, and explain why "one copy is no
copy."
5. Choose the correct aspect ratio (16:9, 9:16, 1:1 or 4:5) for a given platform — YouTube, TikTok/Reels, Instagram feed,
WhatsApp Status — and explain the choice in one sentence.
6. Set up a project correctly: aspect ratio, resolution and frame rate decided before the first cut, and state why setup mistakes
are expensive to fix later.

## D. OPENING ACTIVITY (6 minutes)
<!-- kind:opening -->
Instructor setup: On the projector, show two photographs side by side.
Photo 1: A phone gallery with 247 unsorted videos — random file names like VID_20260314_1832.mp4 , VID_20260314_1835.mp4 ,
VID_20260320_0912.mp4 — all mixed together: a birthday, a shop product, a church choir, a phone screen recording.
Photo 2: A neat filing cabinet, one labelled drawer per event, folders inside, every clip named.
What the instructor says:
"Good morning. Look at these two pictures. Photo 1 is where most people's video lives — a phone gallery with 200, 300, 500
clips, all with names a machine invented, all mixed together. Photo 2 is where a professional editor's footage lives —
sorted, named, backed up, ready to cut.
Now the honest question: hands up if your phone looks like Photo 1. … Almost everybody. Good — you are normal, and
you are exactly who this course is for.
Here is the secret I want you to write down today: an unfinished video is not a footage problem — it is a decision
problem. You already have the clips. What you do not yet have is a reason for each clip and a place for it. Today we build
both."
Expected learner response: Learners will laugh, nod, and say things like "my gallery is worse than that," "I have 1,000 videos," "I
deleted some by mistake once." Accept all answers warmly. Do not let anyone share footage that shows private details.
Then set the frame: Say clearly:
"This course is practical. In three weeks you will edit a complete, professional video for a real-style client brief, using free
software. But professionals do not start by cutting. They start by organising. Today you do the work most beginners skip
— and it is the work that separates a professional from a frustrated phone user."
Why this opener works: It uses a problem every learner recognises instantly (the messy gallery), it removes shame ("you are
normal"), and it frames the editor's real job as decision-making before any software is opened.

## E. PREREQUISITE REVIEW (7 minutes)
<!-- kind:prereq_review -->
Run this as a fast oral round-robin. Put the questions on the projector.
Question 1: "Where do video files normally live on a Windows computer, and how do you open the program that shows them?"
Expected answer: In folders — usually Documents, Downloads, Pictures or the Desktop — and you open File Explorer to
find them.
Common gap: some learners only know the Desktop icon. Show File Explorer briefly on the projector, point out the address
bar and the search box.
Question 2: "What is the difference between a file name and a file type? Give one example of each."
Expected answer: The name is what you call the file ( MamaT_interview_01 ); the type is the format — the part after the dot
( .mp4 , .mov , .jpg ). The type tells the computer how to open it.
Common gap: learners confuse "file type" with "folder." Clarify: the folder is the room; the file type is the shape of the
object inside.
Question 3: "Why is it dangerous to have only one copy of an important file?"
Expected answer: If the phone is lost, the drive fails, or a file is deleted by mistake, the copy is gone forever. One copy is no
copy.
Common gap: many learners have never lost a file yet, so the risk feels theoretical. Use a quick story: "A student lost a whole
project folder to one spilled soft drink. Two copies would have saved it."
Question 4: "Have you ever tried to edit a video on your phone? What was the hardest part?"
Expected answer: "Finding the clip I wanted," "It took too long," "I did not know where the buttons were," "The music was
louder than the talking."
Common gap: learners assume their difficulty means they are "bad at technology." Normalise it: "Every single one of those
is a workflow problem, and workflow is what professionals learn first."
Bridge to today (say this):
"You already know the ingredients — files, folders, names, copies. Today we put them in the order a professional uses. An
editor's job has ten stages, and if you learn the order now, every later session will make sense. Think of it like building a
house: nobody starts with the paint."
If more than a third of the class cannot answer Question 1, spend 5 extra minutes on a quick File Explorer tour before
continuing.

## F. Full Lecture Notes
<!-- kind:lecture -->
F.1 What an editor actually does
The idea. An editor is the person who decides what the audience sees, in what order, and for how long.
Plain-English definition. A camera records everything. An editor chooses the best of it and shapes it into something a stranger
can watch and feel. Editing is decision-making: which shot, which second, which word, which silence, which music.
Why it exists. Raw footage is not a story — it is a pile of possibilities. A two-hour wedding recording contains maybe three
minutes worth showing. A one-minute testimonial interview contains maybe fifteen seconds worth keeping. The editor's job is
to find those moments and cut away everything that works against them.
What an editor contributes to a story:
Selection — choosing the takes where the speaker is clear, warm and honest.
Order — arranging clips so the story makes sense: beginning, middle, end.
Pace — deciding how long each shot stays. Too long, the audience leaves. Too short, they feel rushed.
Sound — making sure the voice is clear and the music supports instead of fights.
Look — making the picture bright, steady and believable.
Feel — the invisible part: the moment you cut here instead of there changes how the viewer feels.
Real-life comparison. Think of a suya stand in Port Harcourt at night. The cook has a big tray of meat, onions, spice, yams. He
does not serve the whole tray. He picks the best pieces, arranges them, adds the right pepper, wraps it, and hands you
something you actually want to eat. An editor is the cook. The footage is the raw tray. The finished video is the wrap.
Important limitation / misconception. Editing cannot fix bad footage completely. If the original video is dark, shaky and noisy,
an editor can improve it — but the result will always be limited by what was captured. This is why professionals say: fix it in
the edit if you can, fix it on set if you can, but know the difference.
How a learner recognises a good editor at work. Watch any video and ask three questions: Did I always know what was
happening? Did the sound feel comfortable? Did it end when it should? If yes to all three, an editor made decisions — and
made them well.
F.2 The ten-stage post-production workflow
The idea. Every professional edit — from a 15-second TikTok to a two-hour film — follows the same backbone. Learn the
order once and you can apply it to any job.
Plain-English definition. The post-production workflow is the ordered list of steps from receiving raw footage to delivering the
finished file and storing the project safely.
The ten stages (say them slowly, write them on the board):

Why the order matters. Stages 1–4 are cheap and slow. Stages 5–10 are fast but expensive to redo. If you cut before you
organise, you will rename files mid-project and break everything. If you export before you check, you will deliver a file with a
spelling error in the title. Professionals protect themselves by doing the boring stages first.
Real-life comparison. The workflow is like cooking a pot of jollof rice. You buy the ingredients (ingest), wash and sort them
(organise), check you have everything (log), keep a spare tin of tomatoes in the cupboard (backup), put the pot on fire
(assembly), taste and adjust (rough cut), get the seasoning exact (fine cut), balance the salt and spice (sound), check the colour
of the rice (colour), plate it and serve it (export/delivery), and write the recipe down so you can cook it again (archive). Nobody
serves the pot before the rice is done.
Nigerian context — what this is worth. Small businesses in Port Harcourt regularly pay ₦15,000–₦50,000 for a clean
30–60 second promo. Churches and event planners pay similar for highlight edits. The people who get paid are not the ones
who know the most buttons — they are the ones whose footage never gets lost, whose edits never have gaps, and whose
delivered files always play. That is workflow.
Common misconception. "The workflow is for big productions; for my phone videos I can skip it." No. A skipped workflow is
why a learner's 200-clip gallery stays messy for three years. The habit is the skill.
F.3 Ingest and organisation — the habit that prevents disaster
The idea. Ingest means moving footage from where it was captured (phone, camera, SD card) into the computer where you
will edit. Organise means giving that footage a clean, predictable home.
Why it exists. Phones lose data. SD cards fail. Files get overwritten. A single careless copy-paste can wipe a whole event. Ingest
done carefully is the moment you take ownership of the material.
The ingest rules (teach these exactly):
1. Copy, never move. During ingest, always copy the files from the phone/card to the computer. Keep the original on the
phone until you have verified the copy. Only then delete the phone's version — and only if the client or owner agrees.
2. Verify before you trust. After copying, open the folder and check: the number of files matches, the total size matches, and
a few clips actually play. A corrupted copy looks identical to a good one until you try to play it.
3. One project, one folder. Every editing job lives in its own folder. Inside it, keep separate sub-folders for 01_Footage ,
02_Audio , 03_Exports , 04_ProjectFiles , 05_Archive . (The full structure is in F.4.)
4. Rename with meaning. Replace VID_20260314_1832.mp4 with MamaT_interview_01.mp4 . A good name tells you what the clip is
without opening it.
The renaming convention used in this course:
```text
ClientOrProject_ShotType_Number
```
Examples: MamaT_interview_01 , MamaT_kitchen_prep_02 , MamaT_exterior_01 . Underscores separate words; the number counts up.
This convention works on every operating system and sorts correctly.
Real-life comparison. Think of sorting a basket of groundnuts. You do not eat from the basket as it comes — you spread it,
remove the stones, group the good ones, and put them in labelled bowls. Ingest is spreading the basket. Organisation is the
labelled bowls.
Common misconception. "I will sort it later." Later never comes, because the edit is urgent and the mess is hidden. The two
minutes spent naming files at the start saves two hours of hunting later.
F.4 The folder structure and the backup rule
The idea. A clean folder structure is a map. A backup is a spare key. Both are cheap; both are skipped by beginners and
regretted by professionals.
The CEA project folder structure (draw this on the board):
```text
CEA-Edit-FirstnameLastname/
├── 01_Footage/
│   ├── PackA_TalkingHead/
│   ├── PackB_ProductBroll/      (added in later sessions)
│   └── PackC_EventMusic/        (added in later sessions)
├── 02_Audio/
│   ├── Music/
│   ├── SFX/
│   └── Voiceover/
├── 03_Exports/
├── 04_ProjectFiles/
│   └── CapCut_Projects/
├── 05_Archive/
└── Docs/
    ├── ShotLogs/
```
```text
    ├── Briefs/
    └── HandoverNotes/
```
Why this works. Numbered folders sort in the right order on every computer. Underscores keep names clean. Every type of
material has exactly one home, so you never wonder where to save something.
The backup rule — "one copy is no copy":
Rule: every clip exists in two separate places before editing starts. Best practice is three (computer + USB drive + cloud),
but two is the course minimum.
Why: drives fail, phones get stolen, laptops get spilled on. The only thing that protects you is a second copy that the first
copy's disaster cannot touch.
The 3-2-1 habit (professionals' version): 3 copies, on 2 different types of storage, 1 off-site. For this course, we practise the
simpler 2-copy rule and explain the 3-2-1 idea as the goal.
Real-life comparison. A backup is like giving your spare house key to your sister who lives in a different street. If your bag
is stolen, you are not locked out. If your USB drive dies, you are not finished.
Nigerian context — a story to tell: "A learner once edited a whole wedding highlights video for two weeks. The night before
delivery, the laptop's hard drive failed. She had no backup. The footage was on the couple's phone, but the couple had already
wiped it for space. She could not deliver. Two copies of the raw footage would have saved the job — and her reputation."
F.5 Aspect ratio — the shape of the screen
The idea. The aspect ratio is the shape of the video frame — the relationship between its width and its height.
Plain-English definition. Aspect ratio is written as two numbers separated by a colon, like 16:9 or 9:16. The first number is the
width, the second is the height. The numbers are a ratio, not a measurement — 16:9 could be 1920×1080 or 1280×720; the
shape is the same.
The four ratios beginners must know (draw each on the board):
Ratio Shape Looks like Used for
16:9 Wide, horizontal A television screen YouTube, websites, TV, presentations, church projection
9:16 Tall, vertical A phone held
upright
TikTok, Instagram Reels, YouTube Shorts, WhatsApp Status
1:1 Square A framed picture Instagram feed posts, Facebook feed
4:5 Slightly tall
rectangle
A portrait photo Instagram feed (higher reach than 1:1 because it fills more of the
phone screen)
How to choose (the decision rule):
1. Ask where the video will be watched. On a laptop or TV → 16:9. On a phone feed → 9:16.
2. Ask what the platform prefers. TikTok, Reels and Shorts are 9:16 by design. Instagram feed can be 4:5 or 1:1. YouTube is
16:9.
3. If you are not sure, choose 9:16 for social-first work — because most phone video is watched vertically.
4. Decide before the first cut. Changing aspect ratio late means re-positioning every title and every keyframed animation.
What happens if you get it wrong. A 16:9 video posted to TikTok gets black bars top and bottom, and looks small and unloved.
A 9:16 video on YouTube gets black bars left and right, and looks amateur. The viewer does not know the word "aspect ratio"
— they just know the video looks wrong.
Real-life comparison. Think of buying a frame for a picture. A wide landscape photo needs a wide frame. A portrait needs a
tall frame. You would not force a tall portrait into a wide frame and leave two empty strips — and you would not shoot a video
in the wrong shape and hope the platform fixes it.
Nigerian context. Most Nigerian phone video is watched on phones — on buses, in shops, in church. This is why 9:16 is the
default for business promos on Instagram and TikTok. But a church service recording for YouTube is 16:9. The professional asks
first.
F.6 Resolution and frame rate — choosing before you cut
The idea. Resolution is how many pixels make up the picture. Frame rate is how many still pictures play per second. Both are
setup decisions — they are expensive to change after editing.
Plain-English definitions:
Resolution — the width × height of the frame in pixels. 1920×1080 (called "1080p" or "Full HD") is the standard for
professional work. 1280×720 ("720p") is acceptable for quick social posts but not for client work.
Frame rate — how many frames (still images) play each second. 30 fps (frames per second) is the standard for online
video worldwide. 25 fps is common in some broadcast traditions. 60 fps is for smooth slow motion.
The rule for this course:
Decision Course standard When to change it
Resolution 1920×1080 for 16:9; 1080×1920
for 9:16
Only if a platform or client specifically asks for something else
Frame rate 30 fps Match the footage; never mix 30 fps and 60 fps in one project
without a reason
Why you must decide before cutting. If you edit at 720p and the client asks for 1080p, you cannot create detail that was never
captured — you can only stretch it, and it looks soft. If you mix frame rates, some clips stutter. Setup is a promise to the whole
project.
Common misconception. "Higher is always better." No. A 4K video on a phone screen is wasted weight, and a 60 fps video of a
talking head looks like a cheap soap opera (the "soap opera effect"). Choose what the story and the platform need.
Real-life comparison. Resolution is like the size of your yam flour — a small bag is fine for one meal, a big bag feeds a family.
Frame rate is like the rhythm of a drummer — 30 is the steady groove of fuji; 60 is the fast roll of a solo. Pick the rhythm of the
song you are playing.
F.7 What the editor contributes beyond the technical
The idea. An editor is not only a technician. An editor is a guardian of the audience's time and trust.
What that means in practice:
You protect attention. Every second you keep is a second the viewer gave you. Waste it and they leave.
You protect truth. You never cut words to change what someone meant. You shorten honestly; you do not deceive.
You protect privacy. If a phone number, plate number or child's face appears, you blur or cut it.
You protect the client's files. You return what is theirs, you keep your copies safe, and you do not reuse their footage
without permission.
The three-line ethics rule (say it with the class):
"Only what we own or licence. Only with consent. Only the truth in the cut."
Why this matters for a career. A client who trusts you with footage, deadlines and honesty comes back. A client whose video
mutates a popular song into a copyright claim, or whose interviewee's words were twisted, tells five other people. In a city like
Port Harcourt, where business runs on relationships, your editing ethics are your brand.
F.8 Summary of the lecture
An editor decides what the audience sees, in what order, and for how long — editing is decision-making.
The workflow has ten stages: ingest → organise → log → backup → assembly → rough cut → fine cut → sound →
colour → titles/export/delivery/archive.
Ingest copies footage safely; organise gives it a clean, named home; log notes what you have; backup puts two copies in
two places.
The folder structure is numbered and consistent: 01_Footage , 02_Audio , 03_Exports , 04_ProjectFiles , 05_Archive , Docs .
Aspect ratio is the frame's shape: 16:9 (wide), 9:16 (tall), 1:1 (square), 4:5 (portrait). Choose before cutting.
Resolution is 1920×1080 (1080p) for this course; frame rate is 30 fps.
The editor is a guardian of attention, truth, privacy and the client's property.

## J. Real-World Case Study
<!-- kind:case_study -->
Situation. Chinedu runs a small phone-accessory shop in Port Harcourt. Over six months he shot 60 videos of products —
power banks, earphones, chargers — all on his phone. He wants to post a promo on Instagram but every time he opens his
gallery he feels overwhelmed and puts it down. A competitor down the street posts clean 30-second videos every week and gets
orders. Chinedu's clips are actually good — clear, well-lit — but they live in a gallery with 2,000 other photos and videos, and
he cannot find the good ones.
Relevant facts.
Chinedu's clips are well-lit and in focus — the shooting is fine.
His gallery has 2,000+ items; product clips are mixed with family photos and screenshots.
He has never made a backup. His phone is two years old and has been repaired once.
He tried editing once, gave up after an hour, and never went back.
Decision point. What is actually stopping Chinedu — his clips, his software, or his workflow?
Possible approaches.
1. Buy a better phone and reshoot everything.
2. Learn to edit fast first, and organise later.
3. Organise, log and back up the existing clips — then edit from a clean set.
Recommended solution. Approach 3. Chinedu's problem is not the quality of his clips — it is that 60 good clips are lost in
2,000 unsorted files with no backup. Reshooting costs money and still leaves the same mess. Learning to edit before organising
means editing in chaos. The professional sequence — organise, log, backup, then edit — costs nothing but two focused hours
and unlocks clips he already has.
Reasoning / what Chinedu would do:
Create a project folder for the promo.
Copy the 60 product clips into 01_Footage .
Rename them Chinedu_product_type_number .
Log them: which show the power bank best, which have the clearest close-up.
Back up to a USB drive and verify.
Now edit — from a clean, findable set.
Trade-offs.
Approach 1: costs ₦150,000+ and still leaves the workflow problem — next month there will be another 60 unsorted clips.
Approach 2: makes the editing harder, because every edit session starts with a treasure hunt through 2,000 files.
Approach 3: costs nothing but time, fixes the root cause, and builds the habit that will serve every future job.
Professional connection. Clients do not pay for footage — they pay for a finished video they can use. A client like Chinedu
will pay ₦15,000–₦30,000 for a clean 30-second promo that makes their products look professional. The editor who can
receive 60 messy clips and return a finished video in two days — because their workflow is disciplined — is the editor who gets
hired again. This is the skill Chinedu needs, and it is the skill this course teaches first.

## K. Common Mistakes and Troubleshooting
<!-- kind:troubleshooting -->
Use this table as the live guide. Point learners to the row rather than giving the answer.
K.1 Moving instead of copying during ingest
Symptoms: The source folder is empty after ingest; if the copy was interrupted, files are lost. Likely cause: Learners drag files
(which moves) instead of copy-pasting (which copies). How to investigate: Ask: "Is the file still in the source folder?"
Corrective steps: Always right-click → Copy, then right-click in the destination → Paste. Keep the original until the copy is
verified. How to confirm resolved: Source folder still has the files after ingest. Prevention: Say the rule out loud at every ingest:
"Copy, then verify, then delete — in that order."
K.2 Skipping the verification step
Symptoms: Files appear copied but some are corrupt or truncated; the edit breaks mid-session. Likely cause: Copying without
checking file counts, sizes and playback. How to investigate: Compare file counts and total sizes between source and
destination; open a sample. Corrective steps: Count files, compare sizes, open at least two clips from the copy. How to
confirm resolved: Count matches, sizes match, clips play. Prevention: Make verification part of the definition of "done" — a
copy is not done until it plays.
K.3 Random file names kept ("I will remember what they are")
Symptoms: In three days, VID_20260314_1832.mp4 is meaningless; the learner cannot find the owner's interview. Likely cause: The
original camera names mean nothing to a human. How to investigate: Show a file with its original name and ask: "What does
this clip show?" Corrective steps: Rename with the convention ClientOrProject_ShotType_Number . How to confirm resolved:
Every file name describes its contents. Prevention: Rename during organisation, not during the edit.
K.4 No backup — "one copy is no copy"
Symptoms: A drive fails or a phone is lost and the footage is gone forever. Likely cause: The learner edited from a single copy
on one device. How to investigate: Ask: "If your USB drive died right now, how many copies of this footage exist?" Corrective
steps: Copy the entire project folder to a second location; verify it. How to confirm resolved: Two copies exist in two places,
both verified. Prevention: Make the backup rule part of every project's setup checklist.
K.5 Choosing the aspect ratio late
Symptoms: Titles and animations are misplaced after a late change; black bars appear on the platform. Likely cause: Aspect
ratio was not decided before editing started. How to investigate: Ask: "Where will this video be watched, and what shape is that
screen?" Corrective steps: Decide the platform first, then the ratio, then set up the project. How to confirm resolved: The
project's aspect ratio matches the delivery platform. Prevention: Make the delivery platform the first question of every job.
K.6 Editing at the wrong resolution
Symptoms: The exported video looks soft or blurry on a big screen. Likely cause: The project was set to 720p when 1080p was
needed, or the footage was lower resolution than the project. How to investigate: Check the project settings against the
delivery spec. Corrective steps: Set the project to 1080p before cutting; never upscale low-resolution footage. How to confirm
resolved: Project settings match the delivery spec and the footage. Prevention: Resolution and frame rate are setup decisions
— decide them before the first cut.
K.7 Skipping the shot log
Symptoms: The rough cut takes three times longer because the learner re-watches every clip to find the good moments. Likely
cause: No log was made during organisation. How to investigate: Ask: "Do you know which clip has the owner's best line?"
Corrective steps: Log every clip: what it shows, sound quality, best moment. How to confirm resolved: The learner can point
to the best clip without re-watching the pack. Prevention: Make the shot log part of organisation — it is the map for the edit.
Distinguish likely vs confirmed: A "likely cause" becomes "confirmed" only after you check it (e.g., the learner can show you
the second copy, or point to the file with the correct name). Teach learners to confirm before concluding.
