## B. Learning Outcomes
<!-- kind:outcomes -->
By the end of this session, the learner will be able to:
1. Identify common data errors — duplicates, inconsistencies, missing values, typos, formatting issues.
2. Standardise formats — dates, phone numbers, names, currency.
3. Remove duplicates using Excel's built-in tools.
4. Fill missing values appropriately.
5. Document all changes made during the cleaning process.
6. Explain why data cleaning is essential for data quality.

## F. FULL LECTURE NOTES (35 minutes)
<!-- kind:lecture -->
Topic 1: Common Data Errors (10 minutes)
Instructor Script: "Here are the most common data errors you will encounter:
1. Inconsistent Date Formats:
'01/10/2026' vs 'October 1, 2026' vs '2026-10-01'
Fix: Standardise to one format (DD/MM/YYYY in Nigeria).
2. Inconsistent Name Formats:
'adaeze okafor' vs 'ADAEZE OKAFOR' vs 'Adaeze Okafor'
Fix: Standardise to Title Case.
3. Misspellings:
'Adaeze' vs 'Adaeeze' vs 'Adaeza'
Fix: Correct the spelling. Use the source document to verify.
4. Duplicate Records:
The same transaction entered twice.
Fix: Identify and remove duplicates.
5. Missing Values:
Empty cells where data should be.
Fix: Fill in the missing data from the source document. If the data is not available, mark it as 'Not Available' or 'N/A'.
6. Inconsistent Currency Formatting:
'₦15,000' vs '15000' vs 'N15,000' vs '15000.00'
Fix: Standardise to ₦ currency format with commas and two decimal places.
7. Extra Spaces:
' Adaeze ' vs 'Adaeze'
Fix: Remove leading and trailing spaces.
8. Wrong Data Types:
Text stored as numbers or numbers stored as text.
Fix: Convert to the correct data type."
Topic 2: Standardising Formats (10 minutes)
Instructor Script: "Standardising means making all data in a column follow the same format. Here is how to standardise each
data type:
Dates:
1. Select the date column.
2. Go to the Home tab.
3. Click the Number Format dropdown.
4. Choose 'Short Date' or 'Custom' and enter DD/MM/YYYY.
Names:
1. Use the PROPER function to convert to Title Case: =PROPER(A1)
2. Copy the result and paste as values.
3. Delete the original column.
Phone Numbers:
1. Ensure all numbers are digits only (no spaces, dashes or symbols).
2. If needed, use the TEXT function to format: =TEXT(A1, "00000000000")
Currency:
1. Select the currency column.
2. Go to the Home tab.
3. Click the Number Format dropdown.
4. Choose 'Currency' and then '₦ English (Nigeria)'."
Topic 3: Removing Duplicates (5 minutes)
Instructor Script: "Excel has a built-in tool to remove duplicate rows.
How to Remove Duplicates:
1. Select the data range.
2. Go to the Data tab.
3. Click 'Remove Duplicates'.
4. Select the columns to check for duplicates.
5. Click OK.
6. Excel removes duplicate rows and tells you how many were removed.
Important Note: Always check the data before removing duplicates. Make sure you are removing true duplicates, not just rows
that happen to have the same value in one column."
Topic 4: Filling Missing Values (5 minutes)
Instructor Script: "Missing values are cells that are empty but should contain data.
How to Fill Missing Values:
1. Identify the missing cells (use Ctrl+G > Special > Blanks to find them).
2. Fill in the missing data from the source document.
3. If the data is not available, enter 'N/A' or 'Not Available'.
4. Document what you filled in and what you could not find.
Important Note: Never make up data. If you do not know the correct value, mark it as missing and flag it for follow-up."
Topic 5: Documenting Changes (5 minutes)
Instructor Script: "When you clean data, you must document every change you make. This creates a record that others can
follow and verify.
What to Document:
1. What errors you found.
2. What changes you made.
3. How you made each change.
4. What data you could not find or correct.
5. The date you made the changes.
Documentation Format: Create a 'Data Cleaning Log' — a separate sheet in the workbook or a separate document that lists all
changes."

## J. REAL-WORLD CASE STUDY (5 minutes)
<!-- kind:case_study -->
Case: "The Report That Was Wrong"
Situation: A business owner asks their administrator to create a sales report from the company's dataset. The administrator uses
the dataset without cleaning it. The report shows incorrect totals because of duplicate rows and missing values. The business
owner makes a decision based on the wrong report and loses money.
The Problem: The dataset was not cleaned before use. Duplicates inflated the totals. Missing values skewed the averages.
Why It Matters: Clean data is the foundation of good decisions. Dirty data leads to wrong conclusions and costly mistakes.
Relevant Concept: Data cleaning. If the administrator had cleaned the dataset first, the report would have been accurate.
Worked Solution: The administrator learns to clean data before using it. They create a cleaning checklist and follow it every
time. The next report is accurate and the business owner makes the right decision.
Transfer Exercise: "Your friend is about to create a report from a dataset. What advice would you give them?"

## K. COMMON MISTAKES AND TROUBLESHOOTING (5 minutes)
<!-- kind:troubleshooting -->
Mistake 1: Not Checking for Duplicates
Symptoms: Totals are inflated because of duplicate rows. Fix: Always check for duplicates before using a dataset.
Mistake 2: Making Up Missing Data
Symptoms: The learner fills in missing values with guessed data. Fix: Never make up data. Use the source document or mark as
N/A.
Mistake 3: Not Documenting Changes
Symptoms: The learner cleans the data but does not record what they changed. Fix: Always create a cleaning log.
Mistake 4: Over-Cleaning
Symptoms: The learner removes data that is actually valid. Fix: Check with the source document before deleting anything.
Mistake 5: Not Standardising Formats
Symptoms: The learner fixes errors but leaves formats inconsistent. Fix: Always standardise formats after fixing errors.

## M. KNOWLEDGE CHECK (5 minutes)
<!-- kind:knowledge_check -->
1. What are the five most common data errors? Answer: Inconsistent formats, misspellings, duplicates, missing values and
wrong data types.
2. How do you remove duplicates in Excel? Answer: Select the data, go to the Data tab, click "Remove Duplicates," select the
columns and click OK.
3. What should you do if you cannot find a missing value? Answer: Mark it as 'N/A' or 'Not Available' and flag it for follow-up.
Never make up data.
4. Why is it important to document data cleaning changes? Answer: It creates a record that others can follow and verify. It also
helps you remember what you did.
5. What Excel function converts text to Title Case? Answer: PROPER
