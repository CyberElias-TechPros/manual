## B. Learning Outcomes
<!-- kind:outcomes -->
By the end of this session, the learner will be able to:
1. Clean a messy dataset — standardise formats, remove duplicates, correct errors.
2. Validate against source documents — identify and resolve discrepancies.
3. Reconcile totals — compare dataset totals with source document totals.
4. Produce a professional data entry report documenting all processes.
5. Present the work to the instructor with confidence.
6. Explain all decisions made during the project.

## E. PREREQUISITE REVIEW (5 minutes)
<!-- kind:prereq_review -->
1. "What are the four main data types?" — Text, numbers, dates and currency.
2. "What is the most efficient way to enter data?" — Column by column, using keyboard shortcuts.
3. "What are the five most common data errors?" — Inconsistent formats, misspellings, duplicates, missing values and wrong
data types.
4. "What is the difference between validation and verification?" — Validation checks standards. Verification checks against
source.
5. "What is reconciliation?" — Comparing two sets of records to ensure they match.

## I. INDEPENDENT CLASS EXERCISE (70 minutes)
<!-- kind:exercise -->
Exercise: "Data Entry Capstone"
Scenario: "You are a data entry professional. You have received a messy dataset and source documents. Complete the project
from raw data to final deliverable."
Task: Complete the following project without assistance:
Step 1: Clean the Dataset (20 minutes)
1. Open the 'Raw Sales Data' file.
2. Identify all errors.
3. Standardise all formats (dates, names, currency).
4. Remove duplicates.
5. Fill missing values or mark as N/A.
6. Correct all typos and calculation errors.
7. Create a cleaning log.
Step 2: Validate Against Source Documents (20 minutes)
1. Open the 'Source Invoices' file.
2. Check every record in the dataset against the matching invoice.
3. Identify and correct all discrepancies.
4. Create a validation report.
Step 3: Reconcile Totals (15 minutes)
1. Calculate the dataset total.
2. Calculate the bank statement total.
3. Compare the totals.
4. Investigate and resolve any differences.
5. Create a reconciliation report.
Step 4: Produce the Data Entry Report (10 minutes) Create a Word document that includes:
Executive summary
Data entry summary
Cleaning summary
Validation summary
Reconciliation summary
Final result
Sign-off
Step 5: Present (5 minutes) Present your work to the instructor. Explain:
What errors you found
How you fixed them
What the final result is
What you learned from the process
Requirements:
Complete all five steps independently.
All errors must be corrected.
All totals must reconcile.
Report must be professional and complete.
Time Allowance: 70 minutes
Success Criteria:
Dataset is clean and validated.
Totals reconcile.
Report is complete and professional.
Presentation is clear and confident.

## K. COMMON MISTAKES AND TROUBLESHOOTING (5 minutes)
<!-- kind:troubleshooting -->
Mistake 1: Not Checking Every Record
Fix: Always check every record against the source.
Mistake 2: Not Documenting the Process
Fix: Always create a report.
Mistake 3: Not Reconciling Totals
Fix: Always compare dataset totals with source totals.
Mistake 4: Presenting Without Preparation
Fix: Review your work before presenting. Be ready to explain your decisions.
Mistake 5: Leaving the Dataset Messy
Fix: Always leave the dataset clean, organised and professional.

## M. KNOWLEDGE CHECK (15 minutes)
<!-- kind:knowledge_check -->
Quiz
Section A: Fundamentals (5 questions)
1. What are the four main data types?
2. What is the most efficient way to enter data into Excel?
3. What does AutoFill do?
4. What is the most important professional standard in data entry?
5. What are the five most common data errors?
Section B: Cleaning (5 questions) 6. How do you remove duplicates in Excel? 7. What should you do if you cannot find a
missing value? 8. What Excel function converts text to Title Case? 9. Why is it important to document data cleaning changes? 10.
What is the standard date format in Nigeria?
Section C: Validation and Reconciliation (5 questions) 11. What is data validation? 12. What is the difference between
validation and verification? 13. What are the five types of discrepancies? 14. What is reconciliation? 15. What should a data entry
report include?
Section D: Integration (5 questions) 16. What are the six steps of the data entry process? 17. Why should you never make up
missing data? 18. What should you do if dataset totals do not match source totals? 19. Why is documentation important for
auditors? 20. What is the most important skill in data entry?
Answer Key
Section A:
1. Text, numbers, dates and currency.
2. Column by column, using keyboard shortcuts.
3. Automatically fills in repetitive data based on a pattern.
4. Accuracy.
5. Inconsistent formats, misspellings, duplicates, missing values and wrong data types.
Section B: 6. Data tab > Remove Duplicates. 7. Mark as N/A and flag for follow-up. 8. PROPER 9. It creates a record others can
follow and verify. 10. DD/MM/YYYY
Section C: 11. The process of checking data against a source to ensure it is accurate and complete. 12. Validation checks that
data meets required standards. Verification checks that data matches the original source. 13. Typo, missing data, extra data,
missing record and calculation error. 14. The process of comparing two sets of records to ensure they match. 15. Executive
summary, data entry summary, cleaning summary, validation summary, reconciliation summary, final result and sign-off.
Section D: 16. Plan, enter, clean, validate, reconcile, document. 17. Making up data is dishonest and can lead to wrong
decisions. 18. Investigate — check for missing records, extra records, amount differences and duplicates. 19. It creates a record
that auditors can follow and verify. 20. Accuracy.
