# Files Folders Digital Workplace

## A. Session Identification
<!-- kind:identification -->
Field Detail
Session Number 3
Title Files, Folders & the Digital Workplace
Field Detail
Week 1
Module The Digital Workplace
Duration 105 minutes
Difficulty Beginner
Prerequisite Knowledge Sessions 1–2 — full computer operation, mouse and keyboard control
Connection to Previous Session Builds on Sessions 1–2 by teaching the learner to store and organise their digital work
Preparation "Messy Files" folder on each desktop, folder structure diagram, handouts printed

## B. Learning Outcomes
<!-- kind:outcomes -->
By the end of this session, the learner will be able to:
1. Explain what a file is and identify common file types (documents, images, videos, audio).
2. Explain what a folder is and why folders are used to organise files.
3. Create a new folder on the Desktop and give it a meaningful name.
4. Rename a folder when the name is not appropriate.
5. Save a file from Notepad into a specific folder.
6. Move a file from one folder to another using cut-and-paste or drag-and-drop.
7. Copy a file to create a duplicate in a different location.
8. Delete a file and restore it from the Recycle Bin.
9. Organise a messy folder of 20 files into a logical folder structure.
10. Explain why good file organisation matters in a professional workplace.

## D. OPENING ACTIVITY (10 minutes)
<!-- kind:opening -->
The "Messy Desk" Analogy
Instructor Setup: Bring a physical file tray or box filled with 20 loose papers (printouts of the sample files). Place it on a table at
the front of the room.
Instructor Script: "Good morning, everyone. Look at this tray. It has 20 papers in it. They are all mixed up — letters,
photographs, receipts, notes. If I asked you to find the 'Budget 2026' paper, how long would it take? [Pause.] A while, right? You
would have to pick up each paper one by one and read it.
Now watch what I do." (Sort the papers into five piles: Documents, Images, Videos, Audio, Miscellaneous.) "I have sorted the
papers into five groups. Now if I ask you to find the 'Budget 2026' paper, where do you look? [Pause.] In the Documents pile.
How long will it take now? [Pause.] Much faster.
This is exactly what we do on a computer. A computer desktop can become just as messy as this tray. Files pile up. You forget
what is where. You waste time looking for things. Today, you will learn how to organise your computer files so that you can find
anything in seconds. This is one of the most important skills you will ever learn. Let us begin."
Expected Learder Response: Recognition that they have experienced this problem on their own computers (or phones). Relief
that there is a solution.

## F. FULL LECTURE NOTES (35 minutes)
<!-- kind:lecture -->
Topic 1: What Is a File? (5 minutes)
Instructor Script: "A file is a single piece of information stored on a computer. It can be a document, a photograph, a video, a
song, a spreadsheet — anything. Every file has a name and a type.
File Names: The name is what you call the file. For example, 'Letter to Bank' or 'Budget 2026.' A good file name tells you what
the file is without opening it. A bad file name tells you nothing. For example, 'Document1' or 'New File' are bad names because
they do not describe the content.
File Types: The type tells you what kind of file it is and what program you need to open it. The type is shown by the extension
— the letters after the dot at the end of the file name. For example:
.txt — a text file (opens in Notepad)
.docx — a Word document (opens in Microsoft Word)
.xlsx — an Excel spreadsheet (opens in Microsoft Excel)
.jpg or .png — an image (opens in a photo viewer)
.mp4 — a video (opens in a media player)
.mp3 — an audio file (opens in a music player)
.pdf — a PDF document (opens in a PDF reader)
Why File Types Matter: If you try to open a video file in a text editor, it will not work. You need the right program for the right
file type. Think of it like this: you cannot play a DVD in a radio. Different formats need different players."
Topic 2: What Is a Folder? (5 minutes)
Instructor Script: "A folder is a container for files. It is like a physical folder that you use to hold papers. You put related files
together in a folder so you can find them easily.
Why Folders Matter: Imagine a computer with 500 files and no folders. Every file is on the desktop, all mixed up. Finding one
file would take hours. Now imagine the same 500 files organised into 20 folders. Each folder has a name like 'Work,' 'Personal,'
'Photos,' 'Music.' You know exactly where to look. Finding one file takes seconds.
Folder Structure: Folders can contain other folders. This is called a folder structure or directory structure. For example:
Desktop
Work
Clients
Client A
Client B
Invoices
Reports
Personal
Photos
Music
Documents
This is like a tree. The Desktop is the trunk. 'Work' and 'Personal' are branches. 'Clients,' 'Invoices' and 'Reports' are smaller
branches. The files are the leaves.
Real-Life Comparison: A folder is like a drawer in a filing cabinet. You do not throw all your papers into one drawer. You have
one drawer for bills, one for receipts, one for personal letters. Folders on a computer work the same way."
Topic 3: File Explorer — Your Digital Filing Cabinet (10 minutes)
Instructor Script: "File Explorer is the program you use to see, organise and manage your files and folders. It is like a window
into your computer's filing cabinet. Let me show you how to open it and what you see.
Opening File Explorer:
1. Look at the taskbar at the bottom of the screen.
2. Find the File Explorer icon. It looks like a yellow folder.
3. Click it once. File Explorer opens.
What You See in File Explorer:
Navigation Pane (left side): This shows the main locations on your computer — Desktop, Documents, Downloads,
Pictures, Music, Videos, and This PC (which shows all drives).
File List (right side): This shows the files and folders in the location you selected.
Address Bar (top): This shows the path to the current location. For example, 'This PC > Desktop' means you are looking at
the Desktop.
Search Box (top-right): This lets you search for files by name.
The Desktop: The Desktop is the first thing you see when you log in. It is a special folder where you can put files and folders for
quick access. Everything on the Desktop is actually stored in a folder called 'Desktop' inside your user account.
Documents, Pictures, Music, Videos: These are special folders that Windows creates for you. They are like labelled drawers in
your filing cabinet. You should save documents in Documents, photos in Pictures, music in Music, and videos in Videos. This
keeps things organised automatically.
This PC: This shows all the storage devices connected to your computer — the hard drive (usually called C:), any USB drives,
and any other storage. The C: drive is where Windows and all your files are stored."
Topic 4: Creating, Naming and Renaming Folders (5 minutes)
Instructor Script: "Now let us learn how to create a folder and give it a good name.
Creating a Folder:
1. Navigate to where you want the folder (e.g., the Desktop).
2. Right-click in an empty space.
3. Click 'New.'
4. Click 'Folder.'
5. A new folder appears with the name 'New folder' highlighted.
6. Type a name for the folder and press Enter.
Naming Folders: A good folder name is:
Descriptive — it tells you what is inside
Short — not more than two or three words
Consistent — use the same style for all folders
Examples of good folder names: 'Work Documents,' 'Family Photos,' 'School Assignments,' 'Business Invoices.' Examples of bad
folder names: 'New folder,' 'Stuff,' 'Things,' 'Misc.'
Renaming a Folder:
1. Right-click on the folder.
2. Click 'Rename.'
3. The name is highlighted. Type the new name and press Enter.
Why Naming Matters: In a professional workplace, other people may need to find your files. If your folders are named 'Stuff'
and 'Things,' no one can find anything. If they are named 'Q1 Sales Report' and 'Client Contracts,' anyone can find what they
need. Good naming is a professional skill."
Topic 5: Saving Files in the Right Place (5 minutes)
Instructor Script: "When you create a file — a document, a spreadsheet, a presentation — you need to save it. Saving means
storing the file on the computer's hard drive so you can find it again later.
How to Save a File:
1. Create your file (e.g., type something in Notepad).
2. Click 'File' in the top-left corner.
3. Click 'Save' or 'Save As.'
4. A dialog box appears. This is where you choose:
Where to save: Click on a folder in the navigation pane (e.g., Desktop, Documents).
What to name the file: Type a name in the 'File name' box.
5. Click 'Save.'
Why 'Save As' Matters: The first time you save a file, always use 'Save As.' This lets you choose the location and the name.
After the first save, you can use 'Save' (or Ctrl+S) to update the file without changing the location or name.
Common Mistake — Saving Everything on the Desktop: Many people save every file on the Desktop. After a few weeks, the
Desktop is covered with files and you cannot find anything. The fix: save files in the appropriate folder. Documents go in
Documents. Photos go in Pictures. Work files go in a Work folder."
Topic 6: Moving, Copying and Deleting Files (5 minutes)
Instructor Script: "Sometimes you need to move a file from one folder to another. Sometimes you need to copy a file so you
have two versions. Sometimes you need to delete a file you do not need anymore. Let us learn how.
Moving a File:
1. Right-click on the file.
2. Click 'Cut.' (This removes the file from its current location and puts it on the clipboard.)
3. Navigate to the destination folder.
4. Right-click in an empty space in the destination folder.
5. Click 'Paste.' (This places the file in the new location.)
Alternatively, you can drag-and-drop: click and hold the file, drag it to the destination folder, and release.
Copying a File:
1. Right-click on the file.
2. Click 'Copy.' (This puts a duplicate on the clipboard. The original stays where it is.)
3. Navigate to the destination folder.
4. Right-click in an empty space.
5. Click 'Paste.' (This places a copy in the new location. The original is still in the old location.)
Deleting a File:
1. Right-click on the file.
2. Click 'Delete.' (This moves the file to the Recycle Bin.)
3. The file is not gone forever. It is in the Recycle Bin.
The Recycle Bin: The Recycle Bin is like a trash can. When you delete a file, it goes to the Recycle Bin. You can restore it if you
change your mind. To restore a file:
1. Double-click the Recycle Bin icon on the Desktop.
2. Right-click on the file.
3. Click 'Restore.'
To permanently delete a file, right-click on it in the Recycle Bin and click 'Delete.' This removes it from the computer
completely. Be careful — you cannot undo this."

## G. INSTRUCTOR DEMONSTRATION (15 minutes)
<!-- kind:demo -->
Demonstration 1: Creating a Folder Structure (5 minutes)
What the Instructor Prepares:
File Explorer open on the projector
The Desktop selected
What the Instructor Says and Does: "I am going to create a folder structure for a small business. The business is called
'Adaeze's Fashion Design.' She needs folders for Invoices, Designs, Customer Records, and Receipts."
1. "I right-click on the Desktop, click 'New,' then 'Folder.' A new folder appears. I type 'Adaeze's Fashion Design' and press
Enter."
2. "Now I double-click on the folder to open it. Inside, I create four sub-folders: 'Invoices,' 'Designs,' 'Customer Records,' and
'Receipts.'"
3. "I right-click, click 'New,' then 'Folder.' I type 'Invoices' and press Enter. I repeat for the other three."
4. "Now I have a folder structure. The main folder is 'Adaeze's Fashion Design.' Inside it are four sub-folders. This is how a
professional organises their work."
What Learners Should Observe: The instructor creating a main folder and four sub-folders, with clear, descriptive names.
Expected Result: Learners can describe the folder structure and explain why it is organised this way.
Questions the Instructor Can Ask:
"Why did I put the sub-folders inside the main folder instead of on the Desktop?" (Answer: So everything is in one place and
easy to find.)
"What would happen if I named the folders 'Folder 1,' 'Folder 2,' etc.?" (Answer: No one would know what is inside them.)
Demonstration 2: Saving a File in a Folder (5 minutes)
What the Instructor Prepares:
Notepad open on the projector
The "Adaeze's Fashion Design" folder created in Demonstration 1
What the Instructor Says and Does: "I am going to type a short note and save it in the 'Invoices' folder."
1. "I type: 'Invoice #001 — Adaeze's Fashion Design — ₦15,000 — Paid.'"
2. "I click 'File,' then 'Save As.'"
3. "In the dialog box, I navigate to the Desktop, then double-click 'Adaeze's Fashion Design,' then double-click 'Invoices.'"
4. "I type 'Invoice 001' in the 'File name' box."
5. "I click 'Save.'"
6. "Now the file is saved in the right place. If I need to find it later, I know exactly where to look: Desktop > Adaeze's Fashion
Design > Invoices > Invoice 001."
What Learners Should Observe: The instructor navigating to the correct folder and giving the file a descriptive name.
Expected Result: Learners can describe the steps to save a file in a specific folder.
Common Errors and Corrections:
If the learner saves the file on the Desktop instead of in the folder: "Check the address bar at the top of the Save dialog. Does
it say 'Desktop' or 'Invoices'? If it says Desktop, navigate to the Invoices folder before saving."
If the learner gives the file a vague name: "What is this file about? Put that in the name. 'Invoice 001' is better than 'New
File.'"
Demonstration 3: Moving and Copying Files (5 minutes)
What the Instructor Prepares:
A few sample files on the Desktop
The "Adaeze's Fashion Design" folder
What the Instructor Says and Does: "I have three files on the Desktop. I want to move two of them into the 'Customer Records'
folder and copy one into the 'Designs' folder."
1. "I right-click on the first file, click 'Cut,' navigate to 'Customer Records,' right-click in the folder, and click 'Paste.' The file
moved."
2. "I right-click on the second file, click 'Cut,' navigate to 'Customer Records,' right-click, and click 'Paste.' That file moved
too."
3. "Now I want to copy the third file into 'Designs.' I right-click, click 'Copy,' navigate to 'Designs,' right-click, and click 'Paste.'
The file is now in both places — the original is still on the Desktop, and a copy is in 'Designs.'"
What Learners Should Observe: The difference between Cut (move) and Copy (duplicate).
Expected Result: Learners can explain the difference between moving and copying a file.
Questions the Instructor Can Ask:
"What is the difference between Cut and Copy?" (Answer: Cut removes the file from the original location. Copy leaves the
original and creates a duplicate.)
"How can you move a file without using the right-click menu?" (Answer: Drag-and-drop.)

## H. GUIDED PRACTICAL EXERCISE (20 minutes)
<!-- kind:guided_practical -->
Exercise: "Build My Filing System"
Practical Objective: The learner will create a folder structure for a fictional small business, save files in the appropriate folders,
and practise moving, copying and deleting files.
Starting Materials:
A "Messy Files" folder on the Desktop containing 20 mixed files
Notepad open
Instructions:
Part 1: Create the Folder Structure (5 minutes)
1. "Right-click on the Desktop. Click 'New,' then 'Folder.' Name it 'My Business.'"
2. "Double-click on 'My Business' to open it."
3. "Inside 'My Business,' create four sub-folders: 'Documents,' 'Images,' 'Media,' and 'Archives.'"
4. "Your folder structure should look like this:
Desktop
My Business
Documents
Images
Media
Archives"
Instructor Prompts:
"Why do we put the sub-folders inside 'My Business' instead of directly on the Desktop?" (Answer: So everything is in one
place.)
"What is the difference between 'Documents' and 'Archives'?" (Answer: Documents are current, active files. Archives are old
files you want to keep but do not need often.)
Part 2: Sort the Messy Files (10 minutes)
5. "Open the 'Messy Files' folder on the Desktop. You will see 20 files."
6. "Your task is to sort these files into the correct folders. Use the file type to decide where each file goes:
Documents (.txt, .docx, .xlsx, .pdf) go in 'Documents'
Images (.jpg, .png) go in 'Images'
Videos (.mp4) and audio (.mp3) go in 'Media'
Everything else goes in 'Archives'"
7. "To move a file: right-click, click 'Cut,' navigate to the destination folder, right-click, click 'Paste.' Or use drag-and-drop."
8. "Sort all 20 files. When you finish, the 'Messy Files' folder should be empty."
Instructor Prompts:
"Where does a .jpg file go?" (Answer: In 'Images.')
"Where does a .mp4 file go?" (Answer: In 'Media.')
"What if you are not sure where a file goes?" (Answer: Look at the file type. If it is still unclear, put it in 'Archives.')
Part 3: Save a File in the Right Folder (5 minutes)
9. "Open Notepad. Type: 'This is a test file for my business. It was created during CEA Session 3.'"
10. "Click 'File,' then 'Save As.'"
11. "Navigate to Desktop > My Business > Documents."
12. "Name the file 'Test File' and click 'Save.'"
13. "Now open File Explorer and verify that the file is in the right place."
Instructor Prompts:
"How do you know the file was saved in the right place?" (Answer: Open File Explorer and navigate to the folder. The file
should be there.)
"What would happen if you saved it on the Desktop instead?" (Answer: It would be mixed in with everything else and hard
to find later.)
Expected Result: Every learner has created a folder structure, sorted 20 files into the correct folders, and saved a Notepad file in
the correct location.
Troubleshooting Guidance:
If the learner cannot find the "Messy Files" folder: "Look on the Desktop. It should be there. If not, ask the instructor to copy
it to your Desktop."
If the learner accidentally deletes a file: "Do not panic. Open the Recycle Bin, right-click on the file, and click 'Restore.'"
If the learner cannot move a file: "Make sure you are right-clicking on the file itself, not on empty space. Then click 'Cut.'
Navigate to the destination folder, right-click in an empty space, and click 'Paste.'"
Completion Checklist:
Created a main folder called "My Business" on the Desktop
Created four sub-folders: Documents, Images, Media, Archives
Sorted all 20 files from "Messy Files" into the correct folders
Saved a Notepad file called "Test File" in the Documents folder
Verified the file is in the correct location using File Explorer

## I. INDEPENDENT CLASS EXERCISE (10 minutes)
<!-- kind:exercise -->
Exercise: "Organise My Documents"
Scenario: "You are helping your aunt, who runs a small restaurant in Port Harcourt. She has a computer, but she saves
everything on the Desktop. Her Desktop is covered with files — recipes, supplier invoices, customer lists, photos of dishes,
music for the restaurant. She cannot find anything. She asks you to help her organise her files."
Task: Without looking at your notes or your neighbour's screen, write down (on a piece of paper or in Notepad) the answers to
these questions:
1. What is the difference between a file and a folder?
2. What are three good folder names for a restaurant business?
3. What are the steps to create a new folder on the Desktop?
4. What are the steps to move a file from the Desktop into a folder?
5. What is the Recycle Bin, and why is it useful?
Requirements:
Write in full sentences where possible
You may look at the computer in front of you for reference
You may NOT look at another learner's paper
Time Allowance: 10 minutes
Success Criteria:
All five questions answered correctly
At least three answers written in complete sentences
The learner can explain their answers to a partner
Hints Available If the Learner Gets Stuck:
Hint 1: "A file is a single piece of information. A folder is a container for files."
Hint 2: "Think about what a restaurant needs: recipes, invoices, customer lists, photos."
Hint 3: "Right-click on the Desktop, click New, then Folder."
Complete Answer Key for the Instructor:
1. What is the difference between a file and a folder?
A file is a single piece of information (a document, image, video, etc.). A folder is a container that holds files and other
folders.
2. What are three good folder names for a restaurant business?
Examples: "Recipes," "Supplier Invoices," "Customer Lists," "Photos of Dishes," "Music," "Staff Records." (Any three
descriptive, relevant names are acceptable.)
3. What are the steps to create a new folder on the Desktop?
Right-click on an empty space on the Desktop. Click "New." Click "Folder." Type a name and press Enter.
4. What are the steps to move a file from the Desktop into a folder?
Right-click on the file. Click "Cut." Open the destination folder. Right-click in an empty space. Click "Paste."
(Alternatively, drag the file into the folder.)
5. What is the Recycle Bin, and why is it useful?
The Recycle Bin is where deleted files are stored temporarily. It is useful because you can restore a file if you delete it by
mistake.

## J. REAL-WORLD CASE STUDY (5 minutes)
<!-- kind:case_study -->
Case: "Ngozi's Organised Business"
Situation: Ngozi runs a small catering business in Port Harcourt. She has a laptop that she uses for everything — recipes,
customer orders, invoices, photos of her dishes, music for events. But she has never organised her files. Everything is on the
Desktop. She has over 100 files and cannot find anything.
One day, a client calls and asks for a copy of an invoice from three months ago. Ngozi spends two hours searching through her
Desktop. She cannot find it. The client gets frustrated and takes their business elsewhere. Ngozi loses ₦50,000.
The Problem: Ngozi's files are not organised. She has no folder structure. She wastes time looking for things. She loses clients
and money because of this.
Why It Matters: In a professional workplace, time is money. If you spend two hours looking for a file, you have wasted two
hours of productive work. Multiply that by every day, every week, and it adds up to thousands of naira lost. Good file
organisation is not just a convenience — it is a professional necessity.
Relevant Concept: Folder structure and file management. If Ngozi had a folder structure — "Invoices," "Recipes," "Customer
Orders," "Photos" — she would find any file in seconds.
Worked Solution: If Ngozi had taken this course, here is what she would do:
1. She would create a main folder called "Ngozi's Catering Business."
2. Inside it, she would create sub-folders: "Invoices," "Recipes," "Customer Orders," "Photos," "Music."
3. She would sort all 100 files into the correct folders.
4. When a client asks for an invoice, she navigates to "Invoices" and finds it in seconds.
5. She saves time, looks professional, and keeps her clients happy.
Reasoning: Good file organisation is like good hygiene. No one notices when it is there, but everyone notices when it is not. It is
a basic professional skill that separates organised people from chaotic people.
Possible Mistake: Ngozi might create too many folders. For example, she might create a separate folder for each client. This
makes the structure too complex and hard to navigate.
Correction: Keep the structure simple. Use broad categories (Invoices, Recipes, Photos) rather than specific ones (Invoice to
Client A, Invoice to Client B). You can always add more folders later if needed.
Transfer Exercise: "Your friend Emeka is a freelance photographer. He has 500 photos on his computer, all in one folder. He
cannot find anything. What folder structure would you recommend?"
Professional Connection: Every office job requires file management. Administrators, accountants, teachers, receptionists,
managers — everyone needs to organise their digital work. This is one of the most basic and most important professional skills.

## K. COMMON MISTAKES AND TROUBLESHOOTING (5 minutes)
<!-- kind:troubleshooting -->
Mistake 1: Saving Everything on the Desktop
Symptoms: The learner saves every file on the Desktop. After a few weeks, the Desktop is covered with files. Likely Cause: The
learner does not know how to navigate to other folders when saving. How to Investigate: Look at the learner's Desktop. Is it
covered with files? Safe Corrective Steps: Teach the learner to use the "Save As" dialog to navigate to the correct folder. Show
them how to click on "Documents" or "This PC" in the navigation pane. How to Confirm the Problem Is Resolved: The learner
saves files in the appropriate folders, not on the Desktop. How to Prevent Recurrence: At the start of every session, ask the
learner where they saved their last file. If they say "Desktop," remind them to use the correct folder.
Mistake 2: Using Vague File Names
Symptoms: The learner names files "Document1," "New File," "Untitled," etc. Likely Cause: The learner does not think about the
file's content when naming it. How to Investigate: Look at the learner's file names. Are they descriptive? Safe Corrective
Steps: Teach the learner to ask themselves: "What is this file about?" The answer should be the file name. For example, "Letter to
Bank" instead of "Document1." How to Confirm the Problem Is Resolved: The learner uses descriptive file names. How to
Prevent Recurrence: At the start of every session, ask the learner to name a file they created. If the name is vague, ask them to
rename it.
Mistake 3: Deleting Files Permanently by Accident
Symptoms: The learner deletes a file and it is gone forever. They cannot restore it. Likely Cause: The learner emptied the
Recycle Bin without checking what was inside. How to Investigate: Ask the learner, "Did you empty the Recycle Bin?" Safe
Corrective Steps: Teach the learner to always check the Recycle Bin before emptying it. Show them how to restore a file from
the Recycle Bin. How to Confirm the Problem Is Resolved: The learner checks the Recycle Bin before emptying it. How to
Prevent Recurrence: Remind the learner at the start of every session: "The Recycle Bin is your safety net. Do not empty it
unless you are sure you do not need anything inside."
Mistake 4: Creating Too Many Folders
Symptoms: The learner creates a separate folder for every file. They have 50 folders and 50 files. Likely Cause: The learner does
not understand that folders are for grouping related files. How to Investigate: Look at the learner's folder structure. Are there
too many folders? Safe Corrective Steps: Teach the learner to use broad categories. For example, instead of "Invoice to Client
A," "Invoice to Client B," "Invoice to Client C," use one folder called "Invoices." How to Confirm the Problem Is Resolved: The
learner uses a simple, logical folder structure. How to Prevent Recurrence: Show the learner examples of good folder
structures and explain the principle of grouping related files.
Mistake 5: Not Saving Work
Symptoms: The learner types a document but does not save it. The computer crashes and the work is lost. Likely Cause: The
learner forgets to save or does not know how. How to Investigate: Ask the learner, "Did you save your work?" Safe Corrective
Steps: Teach the learner to save early and often. Use Ctrl+S every few minutes. Explain that the computer can crash at any time
and unsaved work is lost. How to Confirm the Problem Is Resolved: The learner saves their work regularly. How to Prevent
Recurrence: Remind the learner at the start of every session: "Save early, save often. Ctrl+S is your best friend."

## M. KNOWLEDGE CHECK (5 minutes)
<!-- kind:knowledge_check -->
Questions
1. Multiple Choice: What is the difference between a file and a folder? a) A file is a container, and a folder is a single piece of
information b) A file is a single piece of information, and a folder is a container c) A file and a folder are the same thing d) A
folder is a type of file
Answer: b) A file is a single piece of information, and a folder is a container
2. Short Answer: What are three good file types and what program opens each one?
Answer: .txt (Notepad), .docx (Microsoft Word), .jpg (photo viewer), .mp4 (media player), .mp3 (music player). (Any three
correct pairs are acceptable.)
3. Multiple Choice: What happens when you delete a file? a) It is gone forever b) It goes to the Recycle Bin c) It is moved to the
Desktop d) It is copied to the clipboard
Answer: b) It goes to the Recycle Bin
4. Explain in Your Own Words: Why is it important to use descriptive file and folder names?
Answer: Descriptive names tell you what is inside a file or folder without opening it. This makes it easy to find things quickly.
Vague names like "Document1" or "Stuff" do not help you find anything.
5. Practical Identification: Create a new folder on the Desktop called "Test Folder." Then rename it to "CEA Test."
Answer: The learner successfully creates and renames the folder.
6. Scenario-Based: Your friend says, "I saved my file but I cannot find it. Where did it go?" What are two things you would tell
your friend to check?
Answer: (1) Check the Desktop — the file might be there. (2) Open File Explorer and search for the file name in the search box.
7. Error-Detecting: A learner writes in their assignment: "I moved the file by clicking Copy and then Paste." What is wrong with
this, and what should they write instead?
Answer: Copy and Paste creates a duplicate. The original file stays in the original location. To move a file, the learner should use
Cut and Paste (or drag-and-drop).
