# Operating System Installation

## A. Session Identification
<!-- kind:identification -->
**Week / module:** Week 3 — Module 3: Repair and Maintenance

**Recommended duration:** 105 minutes

**Difficulty:** Beginner (guided, hands-on, safety-critical)

**Prerequisite knowledge:** Sessions 1–8 — components, safety and tools, disassembly/reassembly, the diagnostic workflow, hardware and software diagnostics, component replacement, cleaning and maintenance. A learner must already know how to open a case safely and to back up files.

**Connection to previous work:** In Session 6 you learned to diagnose software faults such as a corrupted operating system. In Session 7 you replaced a hard drive or SSD. Today you complete the natural next step: putting a fresh, working operating system onto a machine so the customer can use it again.

**Preparation before class:** Academy practice PCs ready; a licensed Windows ISO and a USB flash drive (8 GB or larger) per pair; the official Microsoft Media Creation Tool downloaded while the academy internet is working; a spare network/board driver folder on a second USB; a laptop connected to the projector; a printed "OS Install Checklist" and "Customer Intake Form" per learner. Safety flag This is a hands-on, data-destroying session. No drive is wiped in class until (a) data has been backed up and (b) the learner has stated out loud that they understand the wipe is permanent. Only properly licensed Windows is used. Piracy is never taught, demonstrated or tolerated.

## B. Learning Outcomes
<!-- kind:outcomes -->
By the end of this session, the learner will be able to:
1. Explain in plain English what an operating system is and why a corrupted OS sometimes has to be reinstalled rather than
repaired.
2. Back up a customer's data correctly before any wipe, and explain why data safety comes before every other step.
3. Check whether a machine meets the minimum hardware requirements for a given Windows version and say what
happens if it does not.
4. Create a bootable Windows USB drive using the official Microsoft Media Creation Tool, in the correct order.
5. Enter the BIOS/UEFI setup or the one-time boot menu and set or select the correct boot device.
6. Perform a clean install of Windows, correctly choosing "Custom: Install Windows only (advanced)" and installing onto
unallocated space.
7. Explain in beginner terms why we partition a drive and what a clean install removes.
8. Install drivers in the correct order (starting with the network driver) and run Windows Update until no updates remain.
9. Activate Windows using only a legitimate product key or digital licence, and state the academy's rule against piracy.
10. Restore the user's data and complete a post-install verification checklist (Device Manager, display, sound, network,
essential software).

## C. Required Materials
<!-- kind:materials -->
Hardware
At least one practice desktop PC that can be wiped (per pair of learners). If only one machine is available, the instructor
performs the live install while pairs complete the simulated install checklist in parallel.
USB flash drive, 8 GB minimum (16 GB recommended). Note: creating the media erases the USB drive.
A second small USB stick holding the network/board driver and any other offline drivers, in case the installed Windows

Tool kit and an anti-static wrist strap (even though we are not opening the case much, we may reseat cables).
A power socket that learners can reach; keep liquids off the bench.
Software
The official Microsoft Media Creation Tool. Download only from the genuine Microsoft website. As a general guide: search
"Download Windows 11" or "Download Windows 10" from Microsoft, and use the Media Creation Tool page. (Website
layout occasionally changes; the tool name stays the same.)
A valid, licensed Windows product key or a machine with a digital licence already attached to its hardware.
Offline driver files: network/LAN, Wi-Fi, chipset, graphics, audio.
Printed materials
Worksheet 9.1 — "Pre-Installation Checklist".
Worksheet 9.2 — "Post-Installation Verification".
"Customer Intake Form" (reused from Session 10 preparation, to show the data-backup consent line).
Safety equipment
Anti-static wrist strap per learner; safety glasses if compressed air is used during cleaning of the intake vents.
Internet
Required for downloading the Media Creation Tool and the ISO. If the academy internet is slow, download once to a shared

Alternative for learners who lack a facility
A learner who owns a laptop with at least 4 GB RAM and a spare 8 GB USB may practise at home only if they have a
licensed Windows key and have backed up first. If they have only a phone, pair them with a desktop user and have them
fill the printed checklist and narrate the steps.

## D. OPENING ACTIVITY (6 minutes)
<!-- kind:opening -->
Instructor setup: On the projector, show a machine that boots to a black screen with the message "An operating system wasn't
found. Try disconnecting any drives that don't contain an operating system." Or, if unavailable, show a photo of the same
message. Do not explain it yet.
What the instructor says:
"Look at this screen. The customer brought this computer to the shop in tears. It worked yesterday. Today it says the
operating system is gone. She has three years of her shop's records, her children's photos and her church choir videos on it.
She wants it working again — today. Some of you are thinking, 'Just reinstall Windows.' That is exactly right, and it is
what we do today. But look again at her face. If we reinstall carelessly, we destroy everything on that drive. So the real job
is not just installing Windows. The real job is: save her data first, then put the computer right.
Today you will learn to do the whole thing properly: back up, check the machine, build the installer, boot from it, wipe and
install, then bring the machine back to full working order. And we will only ever use a licensed copy of Windows. A repair
shop that pirates software is not a repair shop you can trust."
Expected learner response: Learners may say "just reinstall", "won't the files stay?", or "is the data already lost?". Accept all
answers. Correct gently that a clean install erases the drive and reassure them that backing up first is precisely how we protect
the customer.
Why this opener works: It reframes OS installation from a purely technical task into a customer-trust and data-safety task. That
is the professional mindset this whole week builds. It also plants the licensing rule early.

## E. PREREQUISITE REVIEW (7 minutes)
<!-- kind:prereq_review -->
Run this as a fast oral round-robin. Put the questions on the projector.
Question 1: "Name the six major components of a computer."
Expected answer: motherboard, CPU, RAM, storage (HDD/SSD), PSU, GPU.
Common gap: learners forget the PSU or call the motherboard "the board". Prompt: "Which part turns wall electricity into
the voltages the PC needs?"
Question 2: "What do we call the software that manages all the hardware and lets you run programs?"
Expected answer: the operating system (Windows).
Common gap: learners say "Windows" only. Clarify that Windows is one example of an operating system; others exist
(macOS, Linux). We install Windows in this course.
Question 3: "What is a driver, and what does a yellow exclamation mark in Device Manager mean?"
Expected answer: a driver is software that lets Windows talk to a piece of hardware; a yellow warning means the driver is
missing or not working.
Common gap: learners think drivers are only for printers. Clarify: every major component — chipset, network, graphics,
audio — needs a driver.
Question 4: "According to the diagnostic workflow, what comes before you replace or wipe anything?"
Expected answer: observe, ask questions, form a hypothesis, test. Only after confirming the fault do you act.
Common gap: learners jump to "reinstall". Reinforce: confirm the OS itself is the problem before wiping a working system.
Bridge to today (say this):
"Diagnosing told us the operating system is broken and cannot be repaired cheaply. Today we treat the patient. But
remember the doctor's first rule: do no harm. Before we operate, we save the patient's belongings. That is the backup."
Gap handling: If more than a third of the class cannot explain what a driver is (Question 3), spend five extra minutes drawing a
quick diagram: Windows ↔ driver ↔ hardware, and show a real Device Manager screen with one yellow icon. Do not skip this
— the post-install half of today's session depends on it.

## F. Full Lecture Notes
<!-- kind:lecture -->
F.1 What an operating system actually is
The idea. An operating system (OS) is the master software that sits between the user and the hardware. It starts the computer,
manages memory, storage, files, programs and devices, and gives you the screen you click on.
Plain-English definition. The operating system is the manager of the whole computer. Without it, the hardware is just metal
and silicon that does nothing useful when you press the power button.
Why it exists. Your music player, your browser and your documents cannot each talk directly to the disk and RAM safely —
they would fight over the same memory and files. The OS keeps order: it decides who uses what, when, and how. It also
provides the desktop, the Start menu, the taskbar and the ability to install programs.
What it does.
Boots the machine (loads itself and hands control of the PC to you).
Manages files in folders you can navigate.
Manages memory so programs do not collide.
Talks to hardware through drivers.
Provides security (accounts, passwords, permissions, Windows Defender).
Everyday analogy. Think of a big hotel. The rooms, beds and plumbing are the hardware. The manager (the OS) decides who
gets which room, handles keys (accounts and passwords), makes sure guests do not fight over the same room (memory), and
calls the plumber (driver) when a tap leaks. A hotel with no manager is chaos.
Realistic scenario (Port Harcourt). A cyber café in Rumuola has 8 machines. The café owner bought them with Windows
pre-installed. When a virus corrupts Windows on one machine, the café loses a seat/hour of income. A technician who can
rebuild the OS in under two hours keeps that café earning.
Common misconception. "The operating system is stored on the hard drive, so if Windows breaks, my documents are gone
too." Not automatically true — but a clean install will destroy them if you do not back up first. Files and Windows share the
drive. That is the whole reason data safety is step one.
Limitation. Windows is not free. It requires a valid licence. Installing it without a licence is both unethical and illegal. In this
course we only ever install Windows that has been properly licensed — usually through a key the customer already owns, or a
digital licence tied to that specific machine's hardware.
F.2 When to reinstall the OS — and when not to
The idea. Reinstalling Windows is powerful but heavy-handed. It is the correct fix for some problems and the wrong fix for
others.
Good reasons to do a clean install.
The OS is so corrupted that repair tools (System Restore, Startup Repair, sfc , DISM) fail or the machine will not boot at all.
The drive is being replaced (a new SSD has no operating system on it).
The machine is badly infected with malware that cannot be fully removed.
The customer explicitly wants a fresh start on a machine they own and understand the data consequences.
Reasons NOT to reinstall immediately.
The real fault is hardware (bad RAM, failing drive, failing PSU). Reinstalling Windows on failing RAM just wastes an hour and
frustrates the customer.
The problem is only a missing or faulty driver — install the driver instead.
The user simply lost a file or a program — try to recover or repair first.
The data has not been backed up. You never wipe before you back up. Full stop.
Why this matters professionally. Reinstalling is the technician's version of "have you tried turning it off and on?" If you reinstall
for every problem, customers pay for work they did not need, and their data is put at needless risk. Confirm the diagnosis first.
Common misconception. "A reinstall protects the customer's files automatically because Windows keeps an 'old Windows'
folder." The so-called Windows.old folder is created only in some upgrade situations, not a clean custom install, and it never
contains the user's personal documents. Never rely on it — always back up.
F.3 Data safety first — the backup step
The idea. Before you change, replace or wipe anything, you copy the customer's personal data somewhere safe.
What counts as "the customer's data".
Documents: Word, Excel, PDFs.
Photos and videos (often the most precious).
Their Desktop, Documents, Downloads, Pictures, Music and Videos folders.
Email data if stored locally (for example mailbox files).
Browser bookmarks and passwords where recoverable.
Business records, church or school files, accounting files.
Settings the customer cares about (wallpaper, favourites).
Where to put the backup.
An external hard drive or large USB drive (best for big photo/video collections).
Cloud storage if the customer already has an account and the internet is fast enough.
Never on the same drive you are about to wipe.
Golden rules.
1. Back up before you touch the drive. If the machine will not boot, take the drive out and connect it to a working PC (or a
USB-to-SATA adapter) to copy the files. This is a Session 7 skill in action.
2. Verify the backup by opening a few copied files. A backup you never checked is not a backup.
3. Tell the customer what you could and could not save, and get them to sign the intake form saying they understand a
clean install wipes the rest.
4. Keep the customer's data confidential. Do not share it, post it or copy it for personal use. This is a professional and legal
duty (covered more in Sessions 10 and 11).
Realistic scenario. Mama Ngozi's church office PC will not boot. The secretary's only copy of the harvest records is on it. A
careless technician wipes the drive and installs Windows "fresh" — and destroys two years of records. A professional technician
first pulls the drive, copies the records to an external drive, confirms they open, then wipes. Same one hour of work; completely
different outcome for the customer.
Analogy. The backup is like moving the family photos out of a house before demolishing and rebuilding it. You do not rebuild
first and hope the photos survive.
Limitation / honesty. Sometimes a failing drive cannot be read to back up at all. That is a data-recovery situation — a
specialised, higher-level skill beyond this course. Do not promise the customer data you cannot rescue. Be honest and, if
needed, refer them to a specialist.
F.4 Checking hardware meets requirements
The idea. Before installing an OS, confirm the machine is powerful enough. Installing Windows on a machine below the
minimum requirements leads to a slow, unstable, unhappy result.
General minimums (as a beginner guide).
Version CPU RAM Free storage Other
Windows 10 (64-bit) 1 GHz or faster 2 GB 32 GB DirectX 9 graphics
Windows 11 64-bit, 1 GHz, 2 or more cores 4 GB 64 GB UEFI, Secure Boot capable, TPM 2.0, DirectX 12
Note: Exact figures and the "PC Health Check" wording can change with Windows updates. Always confirm on Microsoft's
requirements page. For this course, the figures above are a safe teaching baseline.
How to check quickly on a working machine.
Press Windows key + Pause/Break (or right-click This PC → Properties) to see processor and installed RAM.
Open This PC to see drive size and free space.
For Windows 11, Microsoft provides a PC Health Check tool that tells you whether a machine qualifies.
Why it exists. Windows 11 in particular refuses to install on many older machines because it requires TPM 2.0 and Secure
Boot, which are security features. A machine without them may be perfectly fine for Windows 10 but not eligible for Windows
11.
Realistic scenario. A student brings a 2012 laptop with 2 GB RAM and asks for "the newest Windows". The honest professional
answer is: Windows 11 needs 4 GB RAM and TPM 2.0, which this machine does not have. Recommend Windows 10 (if it meets
those minimums) or a RAM upgrade — do not force a version the hardware cannot run.
Common misconception. "More RAM, more speed, always." Often true, but a machine whose CPU is very old or whose drive is
a slow HDD will still feel sluggish. Match the OS to the hardware; be honest with the customer.
Limitation. Meeting minimum requirements means Windows will run, not that it will run well. For comfortable everyday use,
recommend more RAM and, ideally, an SSD.
F.5 Creating a bootable Windows USB (Media Creation Tool)
The idea. A "bootable USB" is a USB flash drive that the computer can start from, carrying the Windows installer. We build it
with Microsoft's own free tool.
Why use the official Media Creation Tool.
It is free and comes directly from Microsoft, so the installer is genuine (no tampered, pirated or virus-carrying copies).
It downloads the correct Windows files and formats the USB so the PC can boot from it.
It reduces user error compared with manually formatting drives.
Step-by-step (accurate as of current Windows; menu wording may vary slightly by version).
1. On a working internet-connected PC, go to Microsoft's official download page and get the Media Creation Tool for the
Windows version you intend to install.
2. Back up the USB drive — everything on it will be erased.
3. Plug in a USB flash drive of 8 GB or more.
4. Run the tool and accept the licence terms.
5. When asked what you want to do, choose "Create installation media (USB flash drive, DVD, or ISO file) for another PC".
6. Choose language, edition and architecture (for most modern machines, 64-bit (x64)). If unsure, leave the recommended
defaults.
7. Choose "USB flash drive" as the media type.
8. Select your USB drive from the list — double-check the drive letter and capacity so you do not erase the wrong drive.
9. Click Next and wait. The tool downloads Windows and writes it to the USB. This can take 20–60 minutes depending on
internet speed. Do not unplug the USB or close the tool.
10. When it says "Your USB flash drive is ready", click Finish and safely remove the USB.
How the learner recognises success. The USB now contains folders such as sources , boot , and files such as setup.exe and
bootmgr . If you see those, the media is likely correct.
Realistic scenario. A shop in Diobu cannot afford to keep a DVD writer. The technician keeps one good 16 GB USB with the
official Windows media, plus a second USB with the machine's drivers. Those two sticks rebuild almost any customer PC.
Common misconception. "Any Windows ISO from anywhere is fine." No. Unofficial "cracked" or "activated" ISOs are pirated,
often carry malware, and are against academy policy and the law. Only the official Microsoft tool/ISO and a legitimate licence
are acceptable.
Limitation. The tool needs internet and time, and it wipes the USB. If the academy internet fails, plan ahead: download once
and keep a master USB that you copy from (using a tool like Rufus is a more advanced option, not required for this course).
F.6 BIOS/UEFI and boot order
The idea. When a computer powers on, a tiny program runs before Windows. It checks the hardware and then decides which
device to start from — usually the internal drive, but we need it to start from our USB.
Two names, one job.
BIOS — the older system used by many older machines.
UEFI — the modern replacement; it supports Secure Boot, GPT disks and other security features.
Both do the same basic job: they are the first code that runs and they hand control to a bootloader.
How to get in.
Watch the very first screen for a message like "Press DEL to enter Setup, F2 for BIOS, F12 for Boot Menu." Keys vary by
manufacturer — common ones are Del, F2, F10, F12, Esc, F9.
The one-time boot menu (often F12 , Esc or F9 ) lets you pick the USB for this boot only, without changing settings
permanently. This is the safest and easiest method in a repair shop.
The BIOS/UEFI setup screen (usually Del or F2 ) lets you change the permanent boot order.
What to change.
Put the USB drive first in the boot order, or select it from the one-time boot menu.
For modern Windows 11, ensure UEFI mode is used and Secure Boot is on (if the machine supports it). Secure Boot helps
prevent malware from loading before Windows.
Save and exit (often F10 , then confirm Yes).
Analogy. The BIOS/UEFI is the gatekeeper at the compound gate. Every morning it decides which vehicle is allowed to drive in
first. Normally it lets the family car (the internal drive) in. Today we ask it to let our delivery van (the USB) in first, because it is
carrying the new furniture (Windows).
Realistic scenario. A learner builds the USB correctly but the machine still boots to the old Windows. Cause: the boot order still
points to the internal drive, or the USB was plugged into a port that was not scanned at boot. Fix: use the one-time boot menu
( F12 ) and select the USB explicitly.
Common misconceptions.
"Pressing the key once at any time opens BIOS." It must be pressed repeatedly during the first few seconds, before
Windows starts loading.
"Legacy and UEFI are the same." They boot differently and use different partition styles (MBR vs GPT). Installing in the
wrong mode can make Windows fail to boot.
"Secure Boot is something I must switch off." Do not disable it casually; it is a security feature. Only change it if the machine
genuinely cannot boot the USB and you understand the trade-off.
Limitation. Some manufacturer screens use unusual wording (for example "Boot Option Priorities", "Boot Sequence", "Legacy
Support"). Teach learners that the concept is constant even when the words differ.
F.7 The clean install and partitioning
The idea. A clean install means we install Windows fresh onto a drive that has been emptied of the old system.
Step-by-step during Windows Setup (wording may vary by version).
1. The machine boots from the USB and Windows Setup opens.
2. Choose language, time and currency format, and keyboard layout, then click Next → Install now.
3. If asked for a product key, enter a valid licensed key, or choose "I don't have a product key" if you will activate later with
the customer's key/digital licence. (Windows still needs a valid licence to be legitimate.)
4. Select the edition that matches the customer's licence (for example Windows 10/11 Home or Pro). Do not install an edition
the machine is not licensed for.
5. Accept the licence terms.
6. Choose the installation type. You will see two options:
Upgrade: Install Windows and keep files, settings and applications — keeps the old system's personal files and apps
(only offered when starting Windows from inside a working Windows).
Custom: Install Windows only (advanced) — this is the clean install. Choose this.
7. You now see a list of drives and partitions. To truly clean the drive:
Select each existing partition on the target drive and click Delete.
Repeat until only "Drive 0 Unallocated Space" remains. This permanently erases the drive. (Remember: the backup
is already done.)
Select the unallocated space and click Next.
8. Windows copies files, installs features and updates, and restarts several times. Do not remove the USB until setup has
fully completed and you are at the desktop setup screen. (In some configurations the machine may boot from the USB
again; the one-time boot menu avoids this.)
9. Complete the out-of-box setup (OOBE): region, keyboard, network (if available), user account and password, privacy
settings. Then Windows finishes setting up.
Why partition at all? A partition is a defined section of a physical drive. Windows does not just need one — it creates several
automatically when you install to unallocated space:
An EFI system partition (on UEFI/GPT disks) or a small reserved partition for boot files.
A small Microsoft Reserved partition.
The main Windows (C:) partition where the OS and programs live.
Usually a Recovery partition.
These extra partitions hold the boot files and recovery tools Windows needs. When you install to unallocated space, Windows
creates them for you — you do not have to hand-make them at this level.
Should we split the drive into a C: and a D:? For beginners, keep it simple: let Windows create the C: partition automatically.
Larger businesses sometimes create a separate data partition so that a future reinstall of C: does not touch their documents.
That is a valid technique, but it is optional and must be planned before the wipe.
What a clean install removes.
The old operating system.
All installed programs.
All personal files on that drive (unless backed up).
The old user accounts and settings.
What it does NOT remove.
Files on a different physical drive that you did not touch.
The hardware itself.
Analogy. Partitioning is like drawing rooms on a large empty plot of land. Windows needs a few small utility rooms (boot,
recovery) plus a big living room (C:). Installing to unallocated space is telling Windows: "Here is empty land — build the house
your way."
Common misconception. "If I choose Custom but do not delete partitions, my files are safe." Not necessarily — installing over
an existing partition still overwrites much of it. If you intend to keep data, you must back it up; Custom + Delete is the clean,
predictable choice.
Limitation. A clean install gives you a fresh Windows but no programs, no personal files and no drivers — you must restore
all of those afterwards.
F.8 Drivers, updates, activation, software, data restore and verification
The idea. Installing Windows is only half the job. A freshly installed Windows is like a new house with no furniture, no electricity
connected and no paint. The rest of the work makes it usable.
1. Install drivers — in the right order.
Network driver first. Without it, the PC cannot reach the internet, so you cannot download any other driver. This is why
we keep a copy of the network/board driver on the offline USB.
Then chipset, then graphics, then audio, then Wi-Fi/Bluetooth and any others.
How to install: run the driver installer from your USB, or use Windows Update which often finds common drivers
automatically.
Check Device Manager ( Windows key + X → Device Manager ). A yellow exclamation mark next to a device means a driver is
missing or faulty.
2. Run Windows Update — repeatedly.
Open Settings → Update & Security → Windows Update (Windows 10) or Settings → Windows Update (Windows 11).
Click Check for updates, install everything, and restart when asked.
Repeat until it says no more updates are available. New updates often appear after the first round, so one pass is rarely
enough.
3. Activate Windows — legally.
Open Settings → Update & Security → Activation (Windows 10) or Settings → System → Activation (Windows 11).
If the customer has a valid key, enter it. If the machine has a digital licence tied to its hardware, Windows may activate
automatically after it connects to the internet.
The academy rule: only properly licensed Windows. Never use cracked tools, "activators", key generators or pirated keys.
They are illegal, and they carry malware and leave customers exposed.
4. Install essential software.
A web browser if the customer wants one (Edge is built in).
Windows Defender is already built in — it is the free, legitimate antivirus. Update it.
Only install software the customer is licensed to use. Do not install pirated Microsoft Office or "cracked" versions of paid
programs.
5. Restore the customer's data.
Copy the backed-up files from your external drive back into the customer's Desktop, Documents, Pictures folders.
Check a few files open correctly. Tell the customer what was restored.
6. Post-install verification (the professional finish).
Device Manager: no yellow warning icons.
Display: correct resolution, no weird stretching.
Sound: play a short audio clip; confirm speakers/headphones work.
Network: open a web page; confirm internet and, ideally, Wi-Fi.
Windows Update: fully up to date.
Activation: Windows reports "Windows is activated".
Storage: correct drive shows its full capacity (for example a 500 GB SSD shows roughly 465 GB usable).
Customer sign-off: show the customer the machine working and get them to sign the service report (Session 11).
Analogy. Drivers are like the keys and connections for each appliance in the new house — plumbing to the kitchen, electricity
to every socket. Windows Update is the maintenance schedule that fixes known problems. Activation is the legal title deed
proving the house is properly owned.
Common misconception. "Windows Update installs every driver, so I never need the offline USB." Sometimes true, sometimes
not — especially for network drivers on older or unusual hardware. Always carry the offline network driver. Prepare before you
need it.
Limitation. Some hardware (very new or very old) may need a driver the customer must supply, particularly for specialised
devices like a fingerprint reader or an unusual printer. Be honest if you cannot find one.
F.9 Licensing and ethics — non-negotiable
Only install Windows the customer is licensed to use. A valid product key, or a digital licence already attached to that
machine, is what makes the install legitimate.
Never teach, use or recommend pirated Windows, "cracked" activators, key generators or modified ISOs. They are illegal,
unsafe and damage the academy's and your own reputation.
If a customer asks you to install Windows without a licence, explain politely that you install only properly licensed software,
and offer to help them buy a legitimate licence or use the free, legal alternatives where they fit their needs.
Keep the customer's data confidential and handle it only for the repair.
Say this to the class:
"In this trade, your name is your business. One stolen licence can cost you every customer who hears about it. We do it
right, or we do not do it."
F.10 Summary of the session
The OS manages the whole computer; a clean install is a heavy but sometimes necessary fix.
Back up first — a clean install erases the drive.
Check the machine meets the OS requirements (especially for Windows 11: RAM, TPM 2.0, Secure Boot).
Build a bootable USB with the official Microsoft Media Creation Tool.
Set the boot order / boot menu in BIOS/UEFI.
Choose Custom: Install Windows only (advanced) and install to unallocated space; Windows creates the partitions.
Install drivers (network first), run Windows Update until none remain, activate legally, add essential software, restore
data, and verify with Device Manager and tests.
Only ever use licensed Windows.

## J. Real-World Case Study

Situation. Elias Tech Hub, a repair shop on Ebony Road, Port Harcourt, receives a school laptop from Holy Family Primary

blue recovery screen. The school has a digital licence for Windows 10 Pro on that machine.
Relevant facts.
The drive is a 256 GB SSD and it is readable when connected to another PC.
The term results are in a single Results.xlsx on the Desktop.
The school needs the laptop back the next morning for a PTA meeting.
The technician has the official Media Creation Tool USB and an offline network driver USB.
Decision point. What order of operations protects the school, fixes the machine, and is honest about timing?
Possible approaches.
1. Wipe and reinstall immediately to save time — fastest, but destroys the only copy of the results.
2. Back up first (remove the SSD, copy the file), then clean-install, then restore and verify — safe and professional.
3. Tell the school the data is lost and only fix Windows.
Recommended solution. Approach 2.
Step 1: Remove the SSD and copy Results.xlsx to an external drive; open it to confirm it is intact.
Step 2: Build/boot the official USB; clean-install Windows 10 Pro to unallocated space.
Step 3: Install the network driver, run Windows Update, confirm the digital licence activates automatically (licence is tied
to the machine).
Step 4: Restore Results.xlsx to the Desktop; confirm the teacher can open it.
Step 5: Write the service report (Session 11) and have the teacher sign.
Trade-offs.
Approach 1 saves 30 minutes but risks the school's results and the shop's reputation. Unacceptable.
Approach 2 takes longer but delivers a working, licensed, data-safe result the same day — realistic for a one-hour-grade
job.
Approach 3 abandons the customer needlessly; the data was recoverable.
Professional connection. This is the everyday reality of a repair shop: the technical skill (installing Windows) is only half the job.
The judgement to protect data first and the discipline to use licensed software are what make a technician trustworthy and
keep repeat customers coming back.

## K. Common Mistakes and Troubleshooting
<!-- kind:troubleshooting -->
Use this table as the live troubleshooting guide. When a learner hits an issue, ask them to find the row rather than handing them
the answer.
K.1 Installing before backing up
Symptoms: You realise the customer's files were on the drive and you already deleted the partitions. Likely cause: Skipping data
safety under time pressure. How to investigate: Stop immediately. Do not write any more data to the drive. Safe corrective
steps: If genuinely required and the data is critical, stop all use and refer to a professional data-recovery service — this is
beyond this course and must be handled by a specialist. Do not promise success. How to confirm resolved: A specialist
recovers the data, or you inform the customer honestly. Prevention: Back up and verify before every wipe. Make it an
unbreakable rule.
K.2 USB will not boot
Symptoms: The old system loads, or a "no bootable device" message appears. Likely causes: Wrong boot key, USB not first in
boot order, USB not bootable, or USB in a port not scanned. How to investigate: Enter the boot menu again; check the USB
appears in the list. Try a different (rear) USB port on a desktop. Corrective steps: Rebuild the USB with the official tool if it is not
bootable; select the USB explicitly. Prevention: Use a known-good USB and the official tool; keep the one-time boot key noted.
K.3 "No drives were found" or wrong disk shown
Symptoms: Windows Setup cannot see any drive. Likely causes: A newer machine needs a storage/RAID driver (for example
Intel RST); or the drive is genuinely not detected (loose cable or dead drive — a hardware fault). How to investigate: Check
whether the drive appears in BIOS/UEFI. Reseat cables (safety: power off, anti-static). Corrective steps: Load the storage driver
during setup (advanced), or fix the hardware fault first. Prevention: This is an advanced issue — ask the instructor; do not
guess.
K.4 Internet not working after install
Symptoms: No network, cannot download drivers. Likely cause: Network driver not installed. Corrective steps: Install the
offline network driver from the USB, then run Windows Update. Prevention: Always prepare the network driver before starting.
K.5 Yellow exclamation marks in Device Manager
Symptoms: Device Manager shows warning icons. Likely cause: Missing or faulty drivers. Corrective steps: Identify the device,
install the correct driver (USB or Windows Update). Prevention: Install drivers in order (network, chipset, graphics, audio) and
re-check Device Manager.
K.6 Windows will not activate
Symptoms: "Activate Windows" watermark; activation fails. Likely causes: No valid key/digital licence; not connected to the
internet; edition mismatch. Corrective steps: Connect to the internet and retry; confirm the licence belongs to the machine;
ensure the correct edition was installed. Prevention: Confirm licensing before starting, and never rely on cracks.
K.7 Only one Windows Update pass run
Symptoms: The machine still feels under-updated; some drivers missing. Likely cause: Windows Update was run once.
Corrective steps: Run it repeatedly (restarting) until no updates remain. Prevention: Remember the first pass triggers more
passes.
Distinguish likely vs confirmed: A "likely cause" becomes "confirmed" only after you check it (see the exact error, view BIOS,
check Device Manager). Teach learners to confirm before fixing.

Manager shows no yellow warnings; correct display resolution; sound works; network/internet works; Windows activated;
Windows fully updated; storage shows correct capacity; customer's data restored and opens. (Accept any three correct checks.)
A7. Explain politely that you install only properly licensed Windows, and offer to help them buy a legitimate licence or consider
legal alternatives that fit their needs. You do not install a pirated copy, use a crack/activator, or use a key generator — those are
illegal and unsafe. A8. Any three correct keys, e.g. Del , F2 , F12 (also accept F10 , F9 , Esc ). A9. Installing over an existing
partition can still overwrite much of its contents and does not guarantee the customer's files are safe. The predictable, clean
approach is to back up first, then delete partitions to unallocated space. Never assume files are safe without a verified backup.
A10. Order: 1 Back up the data → 2 Create the bootable USB → 3 Choose Custom and install to unallocated space → 4 Install
the network driver → 5 Run Windows Update until none remain → 6 Verify Device Manager, sound, network and activation.

## N. Reflection and Recap
<!-- kind:reflection -->
Plain-English summary. Today you learned the biggest single job in software repair: putting a fresh operating system onto a
machine. You learned why a corrupted OS sometimes has to be reinstalled, and — most importantly — that data safety
comes first: you back up and verify before you wipe. You checked that the hardware meets the OS requirements, built a
bootable Windows USB with Microsoft's own tool, booted from it through BIOS/UEFI, chose a Custom clean install, wiped to
unallocated space, and understood why Windows creates several partitions. You then finished the job the professional way:
drivers in the right order, Windows Update repeated, legal activation, essential software, restoring the customer's data, and a
full verification. And you committed to using only licensed Windows.
Five important takeaways:
1. Back up first, verify, then wipe — a clean install erases the drive.
2. Build media with the official Microsoft Media Creation Tool; never pirated ISOs.
3. Choose Custom: Install Windows only (advanced) and install to unallocated space.
4. Install the network driver first, then the rest; run Windows Update repeatedly.
5. A machine is finished only when it is updated, legally activated, verified and the customer's data is restored.
Questions to help you recognise what you can now do:
Can I explain the whole install process from backup to verification in my own words?
Can I build a bootable USB with the official tool?
Can I reach the boot menu and boot from that USB?
Can I explain why a clean install is irreversible without a backup?
Can I state the academy's licensing rule without looking it up?
Connection to the next session: You can now fix a machine and hand back a working computer. But a repair shop is not only
about machines — it is about people. Next session you learn customer service: how to greet a customer, capture the fault
accurately in their own words, explain it in plain language, quote honestly, and handle an unhappy customer professionally. The
best technical skill in Port Harcourt will fail if you cannot talk to the person paying for it.

## O. Instructor Evaluation Notes
<!-- kind:instructor_notes -->
Observable signs of genuine competence:
The learner states the backup step first, unprompted, before any mention of wiping.
The learner creates the USB with the official tool and selects the correct drive carefully.
The learner navigates the boot menu/BIOS without being told every key.
The learner chooses Custom and clearly explains that deleting partitions erases data.
The learner installs the network driver first and can say why.
The learner runs Windows Update more than once.
The learner uses only licensed Windows and can state the rule confidently.
The learner completes a real verification (checking Device Manager, sound, network, activation) rather than claiming "it
works".
Common misconceptions to watch for and correct:
"A reinstall is safe without a backup." → A clean install erases the drive. Back up first, always.
"Windows Update installs all drivers automatically." → Often, but not always — especially the network driver. Keep an
offline driver.
"I can use a cracked Windows to save money." → Correct immediately and firmly: only licensed software; piracy is illegal
and unsafe.
"Running Windows Update once is enough." → Run it repeatedly until none remain.
"Choosing Custom keeps my files." → Only if you do not wipe; and never rely on that. Back up.
"BIOS and UEFI are the same thing." → Similar job, different technologies (MBR/legacy vs GPT/UEFI + Secure Boot).
Suggested remedial exercises for learners who struggle:
1. Order-the-steps drill: hand out the nine stages on cards (backup, requirements, media, boot, install, drivers, update,
activate, verify) and have them arrange physically, then explain each.
2. "What could go wrong?" drill: give five unsafe steps (wipe before backup, skip network driver, one update pass, cracked
key, delete wrong partition) and ask for the correct fix.
3. Plain-language drill: ask the learner to explain to a "customer" why the computer needs a fresh Windows and what will
happen to her files.
Differentiation:
Level 1 (supported): provide a partially completed runbook and the full printed checklist; supervise the live install closely;
pair the learner with a stronger peer; allow the simulated install if a live machine is not available to them.
Level 2 (standard): complete the guided practical and independent exercise as written.
Level 3 (challenge): plan a dual-partition layout (C: for Windows, D: for data) before installing; install Windows 11 on a
UEFI/Secure Boot/TPM 2.0 machine; or prepare media with an alternative tool while still using a licensed Windows.
Timing guidance (105 min):
Opening 6, prerequisite review 7, lecture 35, demonstration 15, guided practical 18, independent exercise 15, case study (can
be folded into reflection) 3, reflection/recap plus knowledge check 8. If the room is slow, shorten the case study and protect
the guided practical and the data-safety discussion — those are the priority. Never cut the backup step to save time.
