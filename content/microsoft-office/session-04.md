## B. Learning Outcomes
<!-- kind:outcomes -->
By the end of this session, the learner will be able to:
1. Explain what Microsoft Excel is and what it is used for.
2. Open Microsoft Excel from the Start menu.
3. Identify the main parts of the Excel interface: the Ribbon, worksheet tabs, formula bar, column headers, row headers,
and cells.
4. Navigate between cells using the mouse and keyboard (arrow keys, Tab, Enter).
5. Enter and edit data in cells (text, numbers, dates).
6. Understand cell references (e.g., A1, B2, C3).
7. Save and open workbooks.
8. Apply basic cell formatting: bold, borders, fill colour, number format.
9. Explain why Excel is different from Word and when to use each.

## F. FULL LECTURE NOTES (35 minutes)
<!-- kind:lecture -->
Topic 1: What Is Microsoft Excel? (5 minutes)
Instructor Script: "Microsoft Excel is a spreadsheet program. A spreadsheet is a grid of rows and columns that organises data
into cells. Each cell can contain text, numbers, dates or formulas.
Excel is used for:
Budgets and financial calculations
Sales records and inventory tracking
Student grades and attendance
Data analysis and reporting
Charts and graphs
And much more
Excel vs Word:
Word is for text. Excel is for numbers.
Word is linear (top to bottom). Excel is a grid (rows and columns).
Word is for reading. Excel is for calculating.
Why Excel Matters: Excel is one of the most requested skills in job adverts. Employers want people who can work with
numbers, create budgets and analyse data. If you can use Excel, you are more valuable than someone who cannot."
Topic 2: Opening Excel and the Interface (10 minutes)
Instructor Script: "Let us open Excel and explore the interface.
Opening Excel:
1. Click the Start button.
2. Type "Excel" in the search box.
3. Click on "Microsoft Excel."
4. Excel opens. You will see a start screen with templates. Click "Blank workbook" to create a new spreadsheet.
The Excel Interface — Main Parts:
1. The Title Bar (top): Shows the name of the workbook and the program. By default, a new workbook is called "Book1."
2. The Ribbon (below the title bar): Like Word, the Ribbon contains all the tools, organised into tabs:
File: Open, save, print, export
Home: Font, alignment, number format, cells, editing
Insert: Tables, charts, images, shapes
Page Layout: Margins, orientation, size
Formulas: Functions, named ranges, formula auditing
Data: Sort, filter, data tools
Review: Spelling, comments, protect
View: Zoom, layout views, freeze panes
3. The Formula Bar (below the Ribbon): This shows the contents of the selected cell. If the cell contains a formula, the formula
appears here. If the cell contains a value, the value appears here.
4. The Column Headers (letters): Columns are labelled with letters: A, B, C, D, and so on. There are 16,384 columns in a modern
Excel worksheet.
5. The Row Headers (numbers): Rows are labelled with numbers: 1, 2, 3, 4, and so on. There are 1,048,576 rows in a modern
Excel worksheet.
6. Cells: A cell is the intersection of a column and a row. Each cell has a unique address called a cell reference. For example, the
cell in column A, row 1 is called A1. The cell in column B, row 3 is called B3.
7. The Worksheet Tabs (bottom): A workbook can contain multiple worksheets. Each worksheet is like a separate page. The
tabs at the bottom show the worksheet names (Sheet1, Sheet2, Sheet3). You can add, delete and rename worksheets.
8. The Status Bar (bottom): Shows information about the selected cells, such as the sum, average and count."
Topic 3: Entering and Editing Data (10 minutes)
Instructor Script: "Now let us learn how to enter and edit data in Excel.
Entering Data:
1. Click on a cell. The cell is selected (highlighted with a green border).
2. Type your data (text, number or date).
3. Press Enter to confirm and move to the cell below.
4. Press Tab to confirm and move to the cell to the right.
5. Press Escape to cancel.
Editing Data:
1. Double-click on a cell to edit its contents.
2. Or click on a cell and press F2.
3. Make your changes.
4. Press Enter to confirm.
Deleting Data:
1. Select a cell or range of cells.
2. Press Delete to remove the contents.
3. The cell becomes empty.
Selecting Multiple Cells:
Adjacent cells: Click and drag over the cells.
Non-adjacent cells: Hold Ctrl and click on each cell.
Entire column: Click on the column header (letter).
Entire row: Click on the row header (number).
Entire worksheet: Click the Select All button (the triangle at the top-left corner of the grid).
AutoFill: Excel has a feature called AutoFill that helps you quickly enter data. For example, if you type "January" in a cell and
drag the fill handle (the small square at the bottom-right corner of the cell), Excel will automatically fill in February, March, April,
and so on."
Topic 4: Cell References (5 minutes)
Instructor Script: "Every cell in Excel has a unique address called a cell reference. The reference is made up of the column letter
and the row number.
For example:
A1 is the cell in column A, row 1.
B3 is the cell in column B, row 3.
C10 is the cell in column C, row 10.
Cell references are important because they allow you to refer to specific cells in formulas. For example, if you want to add the
values in A1 and B1, you would write a formula like =A1+B1. We will learn about formulas in the next session.
Types of Cell References:
Relative reference: A1 — changes when you copy the formula to another cell.
Absolute reference: $A$1 — does not change when you copy the formula.
Mixed reference: A$1 or $A$1 — part changes, part does not.
We will learn more about cell references in the next session."
Topic 5: Saving and Opening Workbooks (5 minutes)
Instructor Script: "Saving and opening Excel workbooks works the same way as Word.
Saving a Workbook:
1. Press Ctrl+S or click File > Save As.
2. Choose where to save (Desktop, Documents, etc.).
3. Type a file name.
4. Click Save.
Opening a Workbook:
1. Click File > Open.
2. Navigate to where you saved the workbook.
3. Click on the workbook name.
4. Click Open.
File Extensions:
Excel workbooks have the extension .xlsx (modern format).
Older Excel files have the extension .xls.
When you export to PDF, the extension is .pdf.
Good File Names:
Good: "Monthly Budget 2026," "Sales Report October," "Employee Records"
Bad: "Book1," "Spreadsheet1," "Stuff""

## J. REAL-WORLD CASE STUDY (5 minutes)
<!-- kind:case_study -->
Case: "Adaeze's Budget"
Situation: Adaeze runs a small fashion design business in Port Harcourt. She keeps her financial records in a notebook. She
writes down her income and expenses by hand. At the end of each month, she tries to add up the numbers, but she often makes
mistakes. She loses track of how much money she is making or losing.
One day, a bank manager tells her she needs a proper financial statement to apply for a loan. Adaeze does not know how to
create one. She hires someone to do it for her. It costs her ₦5,000.
The Problem: Adaeze does not know how to use Excel. She wastes time and money keeping records by hand.
Why It Matters: Excel is the standard tool for financial records. If Adaeze knew how to use Excel, she could create her own
budgets, track her income and expenses, and generate professional financial statements. She would save time and money.
Relevant Concept: Excel basics. If Adaeze knew how to enter data, format cells and save workbooks, she could manage her
business finances herself.
Worked Solution: If Adaeze had taken this course, here is what she would do:
1. Open Excel and create a new workbook.
2. Type "Income" in cell A1 and "Expenses" in cell B1.
3. Enter her monthly income and expenses in the cells below.
4. Format the headers as bold with a fill colour.
5. Format the numbers as currency (₦).
6. Save the workbook as "Adaeze's Fashion Budget."
7. Update it every month.
8. Create a professional financial statement for the bank.
Reasoning: Excel makes financial management easy and accurate. You do not have to do mental arithmetic. The formulas do
the math for you (we will learn about formulas in the next session).
Possible Mistake: Adaeze might think Excel is too complicated for a small business. She might think a notebook is good
enough. But a notebook cannot calculate totals, create charts or generate professional reports.
Correction: Excel is not just for accountants and big companies. It is for anyone who works with numbers — and that includes
small business owners.
Transfer Exercise: "Your friend Chinedu sells phone accessories in a shop. He keeps his sales records in a notebook. What
advice would you give him?"
Professional Connection: Every business, no matter how small, needs to track income and expenses. Excel is the most common
tool for this. Knowing how to use Excel makes you more employable and more capable as a business owner.

## K. COMMON MISTAKES AND TROUBLESHOOTING (5 minutes)
<!-- kind:troubleshooting -->
Mistake 1: Typing Data in the Wrong Cell
Symptoms: The learner types data but it appears in a different cell than expected. Likely Cause: The learner did not click on the
correct cell before typing. How to Investigate: Ask the learner, "Which cell did you click on before typing?" Safe Corrective
Steps: Teach the learner to always click on the cell first, then type. Show them how the selected cell is highlighted with a green
border. How to Confirm the Problem Is Resolved: The learner clicks on the correct cell before typing. How to Prevent
Recurrence: Remind the learner: "Click first, then type."
Mistake 2: Not Using Tab and Enter to Navigate
Symptoms: The learner uses the mouse to click on every cell before typing. Likely Cause: The learner does not know about Tab
and Enter shortcuts. How to Investigate: Watch the learner's hands. Are they using the mouse to navigate? Safe Corrective
Steps: Teach the learner to use Tab to move right and Enter to move down. This is much faster than clicking. How to Confirm
the Problem Is Resolved: The learner uses Tab and Enter to navigate. How to Prevent Recurrence: Make Tab and Enter a
standard part of every data entry exercise.
Mistake 3: Not Formatting Numbers as Currency
Symptoms: The learner enters salary data as plain numbers (e.g., 85000) instead of currency (e.g., ₦85,000). Likely Cause: The
learner does not know how to format numbers as currency. How to Investigate: Look at the salary column. Are the numbers
formatted as currency? Safe Corrective Steps: Teach the learner to select the numbers and apply currency format from the
Home tab. How to Confirm the Problem Is Resolved: The learner formats numbers as currency. How to Prevent Recurrence:
Make currency formatting a standard step in every financial data exercise.
Mistake 4: Not Saving the Workbook
Symptoms: The learner enters data but does not save. The computer crashes and the data is lost. Likely Cause: The learner
forgets to save. How to Investigate: Ask the learner, "Did you save your workbook?" Safe Corrective Steps: Teach the learner
to press Ctrl+S regularly. Make it a habit. How to Confirm the Problem Is Resolved: The learner saves regularly. How to
Prevent Recurrence: Set a timer that goes off every 5 minutes. When it rings, everyone presses Ctrl+S.

## M. KNOWLEDGE CHECK (5 minutes)
<!-- kind:knowledge_check -->
Questions
1. Multiple Choice: What is Microsoft Excel? a) A word processing program b) A spreadsheet program c) A presentation
program d) A web browser
Answer: b) A spreadsheet program
2. Short Answer: What is a cell reference?
Answer: A cell reference is the unique address of a cell, made up of the column letter and the row number (e.g., A1, B2, C3).
3. Multiple Choice: What is the difference between a workbook and a worksheet? a) A workbook is a single page, and a
worksheet is a collection of pages b) A workbook is a collection of worksheets, and a worksheet is a single page c) A workbook
and a worksheet are the same thing d) A worksheet is a type of workbook
Answer: b) A workbook is a collection of worksheets, and a worksheet is a single page
4. Explain in Your Own Words: Why is it important to format numbers as currency in a financial spreadsheet?
Answer: Formatting numbers as currency shows that the numbers represent money, not just random digits. It makes the data
easier to read and understand. It also prevents confusion — ₦85,000 is clearly eighty-five thousand naira, while 85000 could be
anything.
5. Practical Identification: Open Excel. Identify the Ribbon, the formula bar, the column headers, the row headers, and the
worksheet tabs.
Answer: The learner correctly identifies all five elements.
6. Scenario-Based: Your friend says, "I entered data in Excel but I cannot find it. Where did it go?" What are two things you
would tell your friend to check?
Answer: (1) Check if the data was saved. If not, it may have been lost. (2) Check if the data is in a different worksheet. Click on
the worksheet tabs at the bottom to see if the data is in Sheet2 or Sheet3.
7. Error-Detecting: A learner writes in their assignment: "I used Word to create my budget because Excel is too complicated."
What is wrong with this, and what should they have done instead?
Answer: Word is not designed for calculations. Excel is the correct tool for budgets because it can perform calculations, format
numbers as currency and create charts. The learner should have used Excel.

Plain-English Summary
Today you learned the fundamentals of Microsoft Excel. You learned what Excel is, how to open it, and how to identify the main
parts of the interface. You learned how to enter and edit data, navigate between cells, and understand cell references. You
learned how to apply basic formatting (bold, fill colour, currency format, borders) and how to save and open workbooks. These
are the foundation skills for everything else you will do in Excel.
Five Important Takeaways
1. Microsoft Excel is a spreadsheet program for working with numbers and data.
2. A cell is the intersection of a column and a row. Each cell has a unique reference (e.g., A1, B2).
3. Use Tab to move right and Enter to move down when entering data.
4. Format numbers as currency when working with financial data.
5. Save regularly with Ctrl+S and use descriptive file names.

Common Misceptions
"Excel is just a bigger Word." Some learners think Excel is a more complex version of Word. Correct this by explaining that
Excel is a grid for numbers, while Word is a page for text.
"I can just click on every cell with the mouse." Some learners use the mouse to navigate instead of Tab and Enter. Correct
this by teaching the keyboard shortcuts.
"Formatting is not important in Excel." Some learners think that only the data matters. Correct this by showing them how
formatting makes data easier to read and more professional.
Suggested Remedial Exercises
For learners who cannot navigate between cells: Have them practise entering data using only Tab and Enter (no mouse).
For learners who cannot format cells: Walk them through the formatting process step by step. Let them practise multiple
times.
For learners who confuse Excel with Word: Show them a side-by-side comparison of Word and Excel. Explain the
differences.
