## B. Learning Outcomes
<!-- kind:outcomes -->
By the end of this session, the learner will be able to:
1. Explain what a formula is and how it differs from manually typed values.
2. Create basic formulas using the equals sign (=) and cell references.
3. Use the SUM function to add a range of cells.
4. Use the AVERAGE function to calculate the mean of a range of cells.
5. Use the COUNT, MIN and MAX functions for basic data analysis.
6. Use AutoSum to quickly calculate totals.
7. Understand relative vs absolute cell references and when to use each.
8. Identify and fix common formula errors (#REF!, #DIV/0!, #VALUE!).
9. Apply number formatting (currency, percentage, decimals) to formula results.
10. Explain why formulas are more efficient than manual calculations.

## F. FULL LECTURE NOTES (35 minutes)
<!-- kind:lecture -->
Topic 1: What Is a Formula? (5 minutes)
Instructor Script: "A formula is a set of instructions that tells Excel to perform a calculation. Every formula starts with an equals
sign (=). This tells Excel that what follows is a formula, not just text.
For example:
=A1+B1 means "add the value in A1 to the value in B1."
=A1*B1 means "multiply the value in A1 by the value in B1."
=A1-B1 means "subtract the value in B1 from the value in A1."
=A1/B1 means "divide the value in A1 by the value in B1."
Why Formulas Matter: If you type a number manually (e.g., 30), it is fixed. If the data changes, you have to recalculate and
retype the number. But if you use a formula (e.g., =A1+B1), Excel recalculates automatically whenever the data changes.
This is why formulas are the most important feature of Excel. They save time, prevent errors and make your spreadsheets
dynamic."
Topic 2: Basic Calculations (10 minutes)
Instructor Script: "Let us learn the four basic calculations: addition, subtraction, multiplication and division.
Addition (+): =A1+B1 adds the values in A1 and B1.
Subtraction (-): =A1-B1 subtracts the value in B1 from the value in A1.
Multiplication (*): =A1B1 multiplies the values in A1 and B1. Note: The multiplication sign in Excel is the asterisk (), not the letter
x.
Division (/): =A1/B1 divides the value in A1 by the value in B1. Note: The division sign in Excel is the forward slash (/), not the
division symbol.
How to Create a Formula:
1. Click on the cell where you want the result to appear.
2. Type = (equals sign).
3. Click on the first cell you want to include in the formula.
4. Type the operator (+, -, *, /).
5. Click on the second cell.
6. Press Enter.
For example, to add the values in A1 and B1:
1. Click on cell C1.
2. Type =
3. Click on cell A1.
4. Type +
5. Click on cell B1.
6. Press Enter.
The result appears in C1. If you click on C1, you can see the formula =A1+B1 in the formula bar."
Topic 3: SUM, AVERAGE, COUNT, MIN, MAX (10 minutes)
Instructor Script: "Excel has built-in functions for common calculations. A function is a predefined formula that performs a
specific task. Let us learn the five most important functions.
SUM: The SUM function adds a range of cells. Syntax: =SUM(range) Example: =SUM(A1:A10) adds all the values from A1 to A10.
AVERAGE: The AVERAGE function calculates the mean of a range of cells. Syntax: =AVERAGE(range) Example:
=AVERAGE(A1:A10) calculates the average of all the values from A1 to A10.
COUNT: The COUNT function counts the number of cells that contain numbers. Syntax: =COUNT(range) Example:
=COUNT(A1:A10) counts how many cells from A1 to A10 contain numbers.
MIN: The MIN function finds the smallest value in a range. Syntax: =MIN(range) Example: =MIN(A1:A10) finds the smallest
value from A1 to A10.
MAX: The MAX function finds the largest value in a range. Syntax: =MAX(range) Example: =MAX(A1:A10) finds the largest value
from A1 to A10.
How to Use a Function:
1. Click on the cell where you want the result to appear.
2. Type = (equals sign).
3. Type the function name (e.g., SUM).
4. Type an opening parenthesis.
5. Select the range of cells you want to include.
6. Type a closing parenthesis.
7. Press Enter.
For example, to calculate the sum of A1 to A10:
1. Click on cell B1.
2. Type =SUM(
3. Select cells A1 to A10.
4. Type )
5. Press Enter.
The result appears in B1."
Topic 4: AutoSum (5 minutes)
Instructor Script: "AutoSum is a shortcut that automatically creates a SUM formula for you. It is the fastest way to calculate
totals.
How to Use AutoSum:
1. Select the cell below the column of numbers you want to add (or to the right of the row of numbers).
2. Go to the Home tab.
3. Click the AutoSum button (Σ) in the Editing group.
4. Excel automatically creates a SUM formula for the adjacent cells.
5. Press Enter to confirm.
AutoSum Tips:
AutoSum works best when you have a column or row of numbers with no gaps.
If AutoSum selects the wrong range, you can adjust the selection before pressing Enter.
You can also access AutoSum from the Formulas tab."
Topic 5: Common Formula Errors (5 minutes)
Instructor Script: "Sometimes formulas produce errors instead of results. Here are the most common errors and how to fix
them.
#DIV/0!: This error occurs when you try to divide by zero. For example, =A1/B1 where B1 is empty or contains zero. Fix: Check
that the cell you are dividing by contains a number, not zero or empty.
#REF!: This error occurs when a formula refers to a cell that does not exist. This usually happens when you delete a row or
column that a formula refers to. Fix: Check the formula and make sure all cell references are valid.
#VALUE!: This error occurs when a formula contains the wrong type of data. For example, =A1+B1 where A1 contains text
instead of a number. Fix: Check that all cells in the formula contain the correct type of data.
#NAME?: This error occurs when Excel does not recognise a function name. This usually happens when you misspell a function.
Fix: Check the spelling of the function name.
How to Debug a Formula:
1. Click on the cell with the error.
2. Look at the formula bar. Check the formula for mistakes.
3. Check the cell references. Are they correct?
4. Check the data types. Are they correct?
5. Fix the mistake and press Enter."

Relevant Concept: Formulas and functions. If Chinedu had known about formulas from the beginning, he would have saved
hours of work and made fewer mistakes.
Worked Solution: If Chinedu had taken this course, here is what he would do:
1. Open Excel and create a new workbook.

3. Use formulas to calculate totals (=Qty*Price).
4. Use SUM to calculate total sales.
5. Use AVERAGE to calculate average sales per product.
6. Use MIN and MAX to find the best and worst performing products.
7. Update the spreadsheet every day.
8. Use the data to make better business decisions.
Reasoning: Formulas turn Excel from a simple data entry tool into a powerful analysis tool. They give you insights that you
cannot get from manual calculations.
Possible Mistake: Chinedu might type the totals manually instead of using formulas. This means he has to recalculate every
time the data changes.
Correction: Always use formulas for calculations. If the data changes, the formula updates automatically.
Transfer Exercise: "Your friend Adaeze sells clothes in a boutique. She keeps her sales records in a notebook. What advice

## K. COMMON MISTAKES AND TROUBLESHOOTING (5 minutes)
<!-- kind:troubleshooting -->
Mistake 1: Forgetting the Equals Sign
Symptoms: The learner types a formula but Excel treats it as text. Likely Cause: The learner forgot to type the equals sign (=) at
the beginning. How to Investigate: Click on the cell. Does the formula bar show the equals sign? Safe Corrective Steps:
Remind the learner that every formula must start with =. How to Confirm the Problem Is Resolved: The learner includes the
equals sign. How to Prevent Recurrence: Remind the learner: "Every formula starts with =."
Mistake 2: Using the Wrong Operator
Symptoms: The learner uses the letter x for multiplication instead of the asterisk (*). Likely Cause: The learner is used to writing
x for multiplication on paper. How to Investigate: Check the formula. Does it use x or *? Safe Corrective Steps: Explain that
Excel uses * for multiplication and / for division. How to Confirm the Problem Is Resolved: The learner uses the correct
operators. How to Prevent Recurrence: Write the operators on the whiteboard: +, -, *, /.
Mistake 3: Not Using Cell References
Symptoms: The learner types =10+20 instead of =A1+B1. Likely Cause: The learner does not understand the importance of cell
references. How to Investigate: Check the formula. Does it use cell references or typed values? Safe Corrective Steps: Explain
that using cell references allows the formula to update automatically when the data changes. How to Confirm the Problem Is
Resolved: The learner uses cell references. How to Prevent Recurrence: Show the learner what happens when they change the
data. The formula updates automatically.
Mistake 4: Dividing by Zero
Symptoms: The formula produces a #DIV/0! error. Likely Cause: The learner is dividing by a cell that is empty or contains zero.
How to Investigate: Check the formula. What cell is the divisor? Safe Corrective Steps: Check that the divisor cell contains a
number, not zero or empty. How to Confirm the Problem Is Resolved: The formula works correctly. How to Prevent
Recurrence: Remind the learner to check for zero and empty cells before dividing.
Mistake 5: Misspelling Function Names
Symptoms: The formula produces a #NAME? error. Likely Cause: The learner misspelled the function name (e.g., =SUMM
instead of =SUM). How to Investigate: Check the formula. Is the function name spelled correctly? Safe Corrective Steps:
Check the spelling of the function name. How to Confirm the Problem Is Resolved: The formula works correctly. How to
Prevent Recurrence: Remind the learner to double-check function names.

## M. KNOWLEDGE CHECK (5 minutes)
<!-- kind:knowledge_check -->
Questions
1. Multiple Choice: What must every Excel formula start with? a) A letter b) A number c) An equals sign (=) d) A function name
Answer: c) An equals sign (=)
2. Short Answer: What is the difference between a formula and a function?
Answer: A formula is any calculation that starts with = (e.g., =A1+B1). A function is a predefined formula that performs a
specific task (e.g., =SUM(A1:A10)).
3. Multiple Choice: What does the SUM function do? a) Calculates the average of a range b) Adds a range of cells c) Counts the
number of cells d) Finds the maximum value
Answer: b) Adds a range of cells
4. Explain in Your Own Words: Why is it better to use formulas instead of typing calculated values manually?
Answer: Formulas update automatically when the data changes. If you type a value manually, you have to recalculate and
retype it every time the data changes. Formulas save time and prevent errors.
5. Practical Identification: Open Excel. Create a formula that adds the values in cells A1, A2 and A3.
Answer: The learner creates the formula =SUM(A1:A3) or =A1+A2+A3.
6. Scenario-Based: Your friend says, "I typed =A1+B1 in Excel but it shows the text '=A1+B1' instead of the result. What did I do
wrong?" What advice would you give?
Answer: You probably forgot to press Enter after typing the formula. Or, the cell is formatted as text. Check the cell format and
make sure it is set to General or Number, not Text.
7. Error-Detecting: A learner writes in their assignment: "I used the formula =A1+B1+C1 to calculate the total, but it shows
#VALUE!." What is wrong, and how can they fix it?
Answer: The #VALUE! error means that one of the cells (A1, B1 or C1) contains text instead of a number. The learner should
check each cell and make sure they all contain numbers.
