# Word Fundamentals

## A. Session Identification
<!-- kind:identification -->
Field Detail
Session Number 1

Week 1
Field Detail
Module Microsoft Word
Duration 105 minutes
Difficulty Absolute Beginner
Prerequisite Knowledge Basic computer operation
Connection to Previous Session First session
Preparation Word installed and open on all machines

## B. Learning Outcomes
<!-- kind:outcomes -->
By the end of this session, the learner will be able to:
1. Explain what Microsoft Word is and what it is used for.
2. Open Microsoft Word from the Start menu or desktop shortcut.
3. Identify the main parts of the Word interface: the Ribbon, tabs, document area, status bar, and Quick Access Toolbar.
4. Type and edit text in a Word document, including inserting, deleting, and replacing text.
5. Select text using the mouse (click and drag) and keyboard (Shift + arrow keys).
6. Cut, copy, and paste text using right-click menu and keyboard shortcuts.
7. Save a document to a specific location with a descriptive file name.
8. Open a saved document from the File menu or recent documents list.
9. Export a document to PDF using the Save As or Export function.
10. Explain why saving work regularly and using descriptive file names matters.

## F. FULL LECTURE NOTES (35 minutes)
<!-- kind:lecture -->
Topic 1: What Is Microsoft Word? (5 minutes)
Instructor Script: "Microsoft Word is a word processing program. A word processing program is software that lets you create,
edit, format and print text documents. It is like a typewriter, but much more powerful. You can undo mistakes, change fonts,
insert images, create tables and much more.
Word is used in almost every office in the world. When a job advert says "proficient in Microsoft Word," they mean you should
be able to create clean, professional documents without help. That is exactly what you will learn in this course.
What Word Is Used For:
Business letters and correspondence
CVs and cover letters
Reports and proposals
Meeting minutes
Flyers, invitations and certificates
Newsletters and brochures
And much more
Word vs Other Tools: You might have used Google Docs or Notepad. Google Docs is similar to Word but works in a web
browser. Notepad is a very basic text editor with no formatting. Word is the professional standard. It has more features than
both and is what most employers expect."
Topic 2: Opening Word and the Interface (10 minutes)
Instructor Script: "Let us open Word and explore the interface. The interface is everything you see on the screen — the buttons,
menus and tools.
Opening Word:
1. Click the Start button (Windows logo in the bottom-left corner).
2. Type "Word" in the search box.
3. Click on "Microsoft Word" in the results.
4. Word opens. You will see a start screen with templates. Click "Blank document" to create a new document.
The Word Interface — Main Parts:
1. The Title Bar (top): This shows the name of the document and the program. By default, a new document is called
"Document1." When you save it, you will give it a real name.
2. The Quick Access Toolbar (top-left): This is a small toolbar with buttons for common actions: Save, Undo and Redo. You
can customise it, but we will leave it as it is for now.
3. The Ribbon (below the title bar): The Ribbon is the most important part of the Word interface. It contains all the tools you
need to create and format documents. The Ribbon is organised into tabs:
File: Open, save, print, export
Home: Font, paragraph, styles, editing
Insert: Tables, images, shapes, headers, footers
Design: Themes, colours, fonts
Layout: Margins, orientation, size
References: Table of contents, citations
Mailings: Mail merge
Review: Spelling, comments, track changes
View: Zoom, layout views
We will use the Home, Insert and Layout tabs most in this course.
4. The Document Area (centre): This is the large white area where you type your document. It looks like a sheet of paper. The
blinking vertical line is called the cursor. It shows where the text will appear when you type.
5. The Status Bar (bottom): This shows information about your document: the page number, word count, language and zoom
level.
6. The Scroll Bars (right and bottom): These let you scroll up and down or side to side to see different parts of your
document."
Topic 3: Typing and Editing Text (10 minutes)
Instructor Script: "Now let us type some text and learn how to edit it.
Typing:
1. Click in the document area. The cursor will appear where you click.
2. Start typing. The text appears at the cursor position.
3. Press Enter to create a new paragraph (a new block of text).
4. Press the space bar to create a space between words.
5. Press Backspace to delete the character to the left of the cursor.
6. Press Delete to delete the character to the right of the cursor.
Selecting Text: To format or edit text, you first need to select it. Selecting means highlighting the text so you know which part
you are working with.
To select a word: Double-click on it.
To select a sentence: Hold Ctrl and click anywhere in the sentence.
To select a paragraph: Triple-click anywhere in the paragraph.
To select all text: Press Ctrl+A.
To select with the mouse: Click and drag over the text.
To select with the keyboard: Hold Shift and use the arrow keys.
Cut, Copy and Paste:
Cut (Ctrl+X): Removes the selected text and places it on the clipboard (temporary storage).
Copy (Ctrl+C): Copies the selected text to the clipboard. The original stays where it is.
Paste (Ctrl+V): Inserts the contents of the clipboard at the cursor position.
Think of it like this: Cut is like cutting out a piece of paper and moving it. Copy is like photocopying a piece of paper. Paste is
like sticking the piece of paper somewhere.
Undo and Redo:
Undo (Ctrl+Z): Reverses your last action. If you make a mistake, press Ctrl+Z.
Redo (Ctrl+Y): Repeats your last action. If you undo something by mistake, press Ctrl+Y.
These are your best friends in Word. Use them often."
Topic 4: Saving and Opening Documents (5 minutes)
Instructor Script: "Saving your work is one of the most important habits you can develop. If you do not save, you lose your
work when the computer crashes or the power goes out.
Saving a Document for the First Time:
1. Click "File" in the top-left corner (or press Ctrl+S).
2. Click "Save As."
3. Choose where to save: Desktop, Documents, or a specific folder.
4. Type a file name in the "File name" box. Use a descriptive name, like "My First Document" or "Business Letter."
5. Click "Save."
Saving an Existing Document: If you have already saved the document, just press Ctrl+S or click the Save icon (floppy disk) in
the Quick Access Toolbar. Word will save the changes without asking for a location.
Opening a Saved Document:
1. Click "File."
2. Click "Open."
3. Navigate to where you saved the document.
4. Click on the document name.
5. Click "Open."
Or, if the document is recent:
1. Click "File."
2. Click "Open."
3. Click on the document name in the "Recent" list.
Good File Names:
Good: "Business Letter to GTBank," "CV Adaeze Okafor," "Meeting Notes October 2026"
Bad: "Document1," "Letter," "Stuff"
A good file name tells you what the document is without opening it. This saves you time when you are looking for a document
later."
Topic 5: Exporting to PDF (5 minutes)
Instructor Script: "PDF stands for Portable Document Format. It is a file format that preserves the exact layout and formatting
of your document. When you send someone a PDF, they see the document exactly as you designed it — regardless of what
software they have on their computer.
PDF is the standard format for sharing finished documents. When you apply for a job and the advert says "send your CV as a
PDF," they mean export your Word document to PDF.
How to Export to PDF:
1. Click "File."
2. Click "Export" (or "Save As" in older versions).
3. Click "Create PDF/XPS Document."
4. Choose where to save the PDF.
5. Type a file name (or keep the same name as the Word document).
6. Click "Publish" or "Save."
You now have two versions of your document: the Word version (which you can edit) and the PDF version (which you share).
Always keep both."

3. "I now have two files on the Desktop: 'My First Document.docx' (the Word version) and 'My First Document.pdf' (the PDF
version)."
What Learners Should Observe: The instructor saving a document and exporting it to PDF.
Expected Result: Learners can describe the steps to save and export to PDF.

## J. REAL-WORLD CASE STUDY (5 minutes)
<!-- kind:case_study -->
Case: "Adaeze's Job Application"
Situation: Adaeze is a fresh graduate. She sees a job advert for an administrative assistant at a company in Port Harcourt. The
advert says to send a CV and cover letter to hr@companyname.com as PDF attachments. Adaeze has a CV, but it is a plain Word
document with no formatting. She opens Word and stares at the screen. She does not know how to make it look professional.
The Problem: Adaeze's CV looks like a school assignment, not a professional document. If she sends it as it is, she will not get
an interview.
Why It Matters: Your CV is often the first impression you make on a potential employer. A poorly formatted CV suggests you
are careless or unskilled. A well-formatted CV suggests you are professional and competent. In a competitive job market, the
difference between a good CV and a bad CV can be the difference between getting an interview and being rejected.
Relevant Concept: Word formatting. If Adaeze knew how to use fonts, sizes, alignment and spacing, she could transform her
plain CV into a professional document.
Worked Solution: If Adaeze had taken this course, here is what she would do:
1. She would open her CV in Word.
2. She would select the headings (name, education, experience) and make them bold and slightly larger.
3. She would use a clean, professional font like Calibri or Arial.
4. She would align the text consistently (left-aligned for body text, centred for the name).
5. She would add spacing between sections.
6. She would save the document and export it to PDF.
7. She would send the PDF to the employer.
Reasoning: Each formatting decision makes the CV easier to read and more professional. A clean, well-organised CV shows that
the candidate cares about details and takes pride in their work.
Possible Mistake: Adaeze might use too many fonts and colours. She might think that more formatting makes it look better. In
reality, too much formatting makes a document look cluttered and unprofessional.
Correction: Use a maximum of two fonts and two colours. Keep it simple and clean. Professional does not mean fancy.
Professional means clear, consistent and easy to read.
Transfer Exercise: "Your friend Chinedu has a CV with five different fonts and three different colours. It looks messy. What
advice would you give him?"
Professional Connection: Every job application requires a CV. Every CV should be professional. This is not optional — it is

## K. COMMON MISTAKES AND TROUBLESHOOTING (5 minutes)
<!-- kind:troubleshooting -->
Mistake 1: Not Saving Regularly
Symptoms: The learner types for 20 minutes without saving. The computer crashes and all work is lost. Likely Cause: The
learner forgets to save or does not realise the importance. How to Investigate: Ask the learner, "When did you last save?" Safe
Corrective Steps: Teach the learner to press Ctrl+S every few minutes. Make it a habit. How to Confirm the Problem Is
Resolved: The learner saves regularly. How to Prevent Recurrence: Remind the learner at the start of every session: "Save
early, save often."
Mistake 2: Typing Over Existing Text
Symptoms: The learner clicks in the middle of a sentence and starts typing, replacing the existing text. Likely Cause: The learner
does not understand the difference between insert mode and overtype mode. How to Investigate: Ask the learner, "What
happened to the text after the cursor?" Safe Corrective Steps: Explain that Word is usually in insert mode (new text pushes
existing text forward). If the learner accidentally pressed the Insert key, it switches to overtype mode (new text replaces existing
text). Press the Insert key again to return to insert mode. How to Confirm the Problem Is Resolved: The learner types in insert
mode. How to Prevent Recurrence: Show the learner where the Insert key is and explain what it does.
Mistake 3: Using the Space Bar Instead of Tab or Indent
Symptoms: The learner presses the space bar five times to indent a paragraph. Likely Cause: The learner does not know about
the Tab key or the indent button. How to Investigate: Ask the learner, "How did you indent the paragraph?" Safe Corrective
Steps: Teach the learner to use the Tab key to indent the first line of a paragraph. Or use the Increase Indent button on the
Home tab. How to Confirm the Problem Is Resolved: The learner uses Tab or the indent button. How to Prevent
Recurrence: Show the learner the Tab key and the indent button. Explain that using the space bar for indentation is unreliable.
Mistake 4: Not Exporting to PDF
Symptoms: The learner saves the Word document but does not export it to PDF. Likely Cause: The learner does not know how
or does not understand why PDF is important. How to Investigate: Ask the learner, "Did you export to PDF?" Safe Corrective
Steps: Show the learner how to export to PDF. Explain that PDF is the standard format for sharing finished documents. How to
Confirm the Problem Is Resolved: The learner exports to PDF. How to Prevent Recurrence: Make PDF export a standard step
in every assignment.
Mistake 5: Using Descriptive File Names
Symptoms: The learner saves files as "Document1," "Document2," "Document3." Likely Cause: The learner does not change the
default file name. How to Investigate: Ask the learner, "What did you name the file?" Safe Corrective Steps: Teach the learner
to always use a descriptive file name. Show them examples of good and bad file names. How to Confirm the Problem Is
Resolved: The learner uses descriptive file names. How to Prevent Recurrence: Remind the learner at the start of every save:
"What is this document about? Put that in the name."

## M. KNOWLEDGE CHECK (5 minutes)
<!-- kind:knowledge_check -->
Questions
1. Multiple Choice: What is Microsoft Word? a) A spreadsheet program b) A word processing program c) A presentation
program d) A web browser
Answer: b) A word processing program
2. Short Answer: What are the main parts of the Word interface?
Answer: Title bar, Quick Access Toolbar, Ribbon (with tabs), document area, status bar, and scroll bars.
3. Multiple Choice: What does Ctrl+S do? a) Select all text b) Save the document c) Copy text d) Print the document
Answer: b) Save the document
4. Explain in Your Own Words: Why is it important to export a document to PDF?
Answer: PDF preserves the exact layout and formatting of the document. When you send someone a PDF, they see the
document exactly as you designed it, regardless of what software they have. PDF is the standard format for sharing finished
documents.
5. Practical Identification: Open Word. Identify the Ribbon, the Home tab, the document area, and the status bar.
Answer: The learner correctly identifies all four elements.
6. Scenario-Based: Your friend says, "I typed a whole page but then the computer crashed and I lost everything. What did I do
wrong?" What advice would you give?
Answer: You should have saved your work regularly. Press Ctrl+S every few minutes. Saving takes two seconds and protects
your work from crashes and power outages.
7. Error-Detecting: A learner writes in their assignment: "I saved my file as 'Document1' on the Desktop." What is wrong with
this, and what should they have done?
Answer: "Document1" is a vague default name. The learner should have used a descriptive name that tells them what the
document is, like "Letter to Landlord" or "Meeting Notes October 2026."

## O. Instructor Evaluation Notes
<!-- kind:instructor_notes -->
Observable Signs of Competence
The learner opens Word independently.
The learner identifies the Ribbon, tabs and document area.
The learner types, selects, cuts, copies and pastes text.
The learner saves with a descriptive file name.
The learner exports to PDF.
The learner uses Ctrl+Z and Ctrl+Y confidently.
Common Misconceptions
"Word is just for typing." Some learners think Word is only for typing text. Correct this by showing them the formatting
tools and explaining that Word is for creating professional documents.
"Saving and exporting are the same thing." Some learners think saving a Word document is enough. Correct this by
explaining that PDF is the format you share with others.
"Ctrl+Z is only for mistakes." Some learners think undo is only for fixing errors. Correct this by explaining that undo is a
tool for exploring — you can try something, undo it, and try something else.
Suggested Remedial Exercises
For learners who cannot find the Ribbon: Print a labelled Word interface diagram and have the learner label each part.
For learners who forget to save: Set a timer that goes off every 5 minutes. When it rings, everyone presses Ctrl+S.
For learners who cannot export to PDF: Walk them through the process step by step. Let them practise multiple times.
Differentiation Guidance
Level 1 — Supported (for learners who struggle):
Provide a labelled Word interface diagram for reference.
Pair with a more confident learner for practical exercises.
Allow extra time for the independent exercise.
Focus on typing and saving before formatting.

Complete all exercises as written.
Answer all knowledge check questions.
Complete the assignment to the standard shown in the rubric.
Level 3 — Challenge (for learners who finish early):
Ask the learner to create a more complex document (e.g., a two-page report with headings and subheadings).
Ask the learner to research and write down three more keyboard shortcuts.
Ask the learner to explain the difference between Save and Save As.
